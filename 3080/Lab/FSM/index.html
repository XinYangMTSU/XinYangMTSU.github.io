Learning goals

Identify states, input symbols, transitions, initial states, and state-dependent outputs; trace a finite-state machine through an input sequence; and use a four-state binary adder to compute sums, least-significant-bit first.

From the course handouts: The examples use the three-state machine from Example 29, where outputs are determined by the current state, and the binary adder with states tracking both output bit and carry. The initial state's output is not counted as an output produced by the first input.
