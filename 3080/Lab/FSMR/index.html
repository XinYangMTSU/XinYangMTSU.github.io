Learning goals

Use a finite-state machine to recognize patterns in binary input. Trace state changes and outputs, distinguish an odd parity checker from an even parity checker, recognize strings whose final symbols are 101, and explain final states.

Lecture examples: An odd parity checker outputs 1 when the number of 1s read so far is odd. The four-state recognizer outputs 1 only when the input received so far ends in 101. The initial state's output is displayed, but it is not counted as an output produced by processing the first input.
