Gaussian Elimination — Interactive Learning Lab

Learn the process: represent → pivot → eliminate → back-substitute → extend to RREF.

Step 1 of 8

Why Gaussian Elimination?

x + y = 70
24x + 14y = 1180
Gaussian elimination transforms a system into an equivalent system that is easier to solve.
Step 2 of 8

Build the augmented matrix

[ 1   1 | 70 ]
[ 24   14 | 1180 ]

The left side stores coefficients; the rightmost column stores constants.

Step 3 of 8

Three elementary row operations

Swap

R₁ ↔ R₂

Scale

Rᵢ ← cRᵢ, c ≠ 0

Replace

Rᵢ ← Rᵢ + cRⱼ

Key idea

All preserve the solution set.

We can swap rows, multiply a row by a nonzero number, or add a multiple of one row to another. Which operation below is NOT allowed?

Step 4 of 8

Create the first zero

[ 1   1 | 70 ]
[ 24   14 | 1180 ]

Use the first pivot to eliminate 24.

Target: make the first entry of row 2 equal to 0.
Step 5 of 8

Upper triangular form

[ 1   1 | 70 ]
[ 0   −10 | −500 ]
Everything below the main diagonal is now zero. Standard Gaussian elimination can stop and use back-substitution.
Step 6 of 8

Back-substitution

−10y = −500 → y = 50

x + 50 = 70 → x = 20
Solution: x = 20, y = 50
Step 7 of 8

Gaussian vs. Gauss–Jordan

You have already used Gaussian Elimination to reach:

[ 1   1 | 70 ]
[ 0   −10 | −500 ]
Gaussian Elimination can stop here. The matrix is in row echelon form, so we can use back-substitution. Gauss–Jordan keeps going until the coefficient part becomes the identity matrix.
Gaussian EliminationGauss–Jordan Elimination
Zeros below pivotsZeros above and below pivots

Pivots do not have to be 1Every pivot is 1

Gaussian→REF→Back-substitution
Gauss–Jordan→REF→Keep going→RREF

Let's continue using Gauss–Jordan

Goal: change the coefficient part from [ 1   1 ; 0   −10 ] into the identity matrix [ 1   0 ; 0   1 ].

Step A: Make the second pivot 1

The second pivot is −10. What should we multiply Row 2 by?

Correct. R₂ ← −(1/10)R₂
[ 1   1 | 70 ]
[ 0   1 | 50 ]

Step B: What must happen above the second pivot?

The second pivot is now 1. For RREF, what should happen to the 1 above it?

Which row operation will do that?

Correct. Since 1 − 1 = 0, R₁ ← R₁ − R₂ eliminates the entry above the pivot.
[ 1   0 | 20 ]
[ 0   1 | 50 ]
RREF reached! The coefficient matrix is now the identity matrix.
Read the solution directly: x = 20, y = 50.
Step 8 of 8

Application: Matrix Inverse

[ A | I ] → [ I | A⁻¹ ]

For A = [1 2; 3 2], Gauss–Jordan can turn the left side into I.

A⁻¹ = [ −1/2   1/2 ; 3/4   −1/4 ]
Mastery: Gaussian elimination simplifies to echelon form; Gauss–Jordan continues to RREF.
