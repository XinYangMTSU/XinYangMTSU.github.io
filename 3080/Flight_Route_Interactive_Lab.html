Step 3 of 9

Why Use a C++ map?

map<string, int> cityIndex; for (int i = 0; i < CITY_COUNT; i++) { cityIndex[cities[i]] = i; }
"NYC" → 0   "LAX" → 1   "ORD" → 2   "DFW" → 3
The map converts a meaningful city name into the integer index required by the matrix.
Step 4 of 9

Read the Flight Adjacency Matrix

int flightMatrix[CITY_COUNT][CITY_COUNT] = { {0,1,1,0}, {1,0,1,0}, {1,1,0,1}, {0,0,1,0} };
1 = direct flight exists.   0 = no direct flight.

Step 7 of 9

Validate City Names

if (cityIndex.find(city1) == cityIndex.end() || cityIndex.find(city2) == cityIndex.end()) { cout << "Invalid city names."; return; }
find() searches for a key. If the result equals end(), the city name was not found.
Step 8 of 9

Direct Flight vs. Connecting Route

int index1 = cityIndex[city1]; int index2 = cityIndex[city2]; if (matrix[index1][index2] == 1) cout << "Yes! Direct flight available"; else cout << "No! No direct flight";
NYC → DFW: flightMatrix[0][3] = 0
No direct flight does not mean no possible route. In this graph, NYC can reach DFW through ORD: NYC → ORD → DFW.
Step 9 of 9

Why the do–while Loop?

do { checkFlight(flightMatrix, cities, cityIndex); cout << "Check another flight? (y/n): "; cin >> choice; } while (choice == 'y' || choice == 'Y');

y or Y

Run another flight query.

Anything else

Leave the loop and end the program.

A do–while loop runs the body at least once before testing the condition.

Quick Check

Why is a do-while loop appropriate for this program?
Think about the order: first checkFlight() runs, then the program asks y/n, and only then is the loop condition tested.
Run Once → Ask y/n → Test Condition → Repeat or Exit
