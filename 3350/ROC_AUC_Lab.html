Probability → threshold → confusion matrix → TPR/FPR → ROC → AUC → threshold choice.

1. Why do we need ROC?

You already know Accuracy, Precision, Recall, Specificity, and F1. But those values depend on the classification threshold.

Question: Why must the cutoff always be 0.50? It does not. Changing the threshold changes predictions and evaluation metrics.

5. False Positive Rate (FPR)

TPR = TP/(TP+FN) = Recall = Sensitivity
FPR = FP/(FP+TN) = 1 − Specificity
ROC plots FPR on X and TPR on Y.

7. Many thresholds = ROC curve

Many thresholds → Many ROC points → ROC curve

Every threshold creates a different confusion matrix and therefore a different TPR/FPR pair.

8. What does a good ROC curve look like?

Upper-left

High TPR, low FPR — desirable.

Diagonal

No-skill/random-ranking reference.

Ideal point: FPR = 0, TPR = 1

9. AUC: summarize the whole ROC curve

AUCInterpretation
1.0Perfect separation
0.5No-skill/random ranking
>0.5Better than random ranking
Intuition: AUC is the probability that a randomly selected positive receives a higher score than a randomly selected negative.

11. Can ROC help choose a threshold?

Youden J = TPR − FPR = Sensitivity + Specificity − 1
Maximizing J gives one balanced threshold when sensitivity and specificity are weighted equally.
Important: there is no universally best threshold. Application costs matter.

13. ROC and AUC in Python

from sklearn.metrics import roc_curve, roc_auc_score import matplotlib.pyplot as plt y_score = model.predict_proba(X_test)[:, 1] fpr, tpr, thresholds = roc_curve(y_test, y_score) auc = roc_auc_score(y_test, y_score) plt.plot(fpr, tpr, label=f"AUC = {auc:.3f}") plt.plot([0, 1], [0, 1], "--") plt.xlabel("False Positive Rate") plt.ylabel("True Positive Rate") plt.legend() plt.show()
ROC uses probability/score outputs, not only final 0/1 predictions.
