From 5-Fold CV to Nested Cross-Validation

Step-by-step walkthrough: OUTER StratifiedKFold + INNER GridSearchCV.

1. Big Picture

5 stratified folds
→
Train on 4
→
Test on 1
→
Repeat ×5
Main idea: every fold is held out once. We calculate five sets of metrics and then average them.
Now we add GridSearchCV: StratifiedKFold is the OUTER CV used for performance evaluation. GridSearchCV performs the INNER CV used to choose hyperparameters.
INNER CV chooses hyperparameters → OUTER CV evaluates performance
OUTER Train
→
INNER GridSearchCV
5 folds
choose k or C
→
best_estimator_
→
OUTER Test

2. Imports and SEED

import numpy as np import pandas as pd import matplotlib.pyplot as plt from sklearn.model_selection import StratifiedKFold, GridSearchCV from sklearn.metrics import ( accuracy_score, precision_score, recall_score, f1_score, roc_curve, auc ) SEED = 42
pandas builds the results table; matplotlib plots ROC curves; StratifiedKFold creates folds; metric functions evaluate predictions. SEED=42 makes shuffled splits reproducible.

3. Build Pipelines + INNER GridSearchCV

from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.neighbors import KNeighborsClassifier from sklearn.linear_model import LogisticRegression knn_pipe = Pipeline([ ("scaler", StandardScaler()), ("knn", KNeighborsClassifier()) ]) knn_grid = { "knn__n_neighbors": np.arange(1, 31, 2) } knn_search = GridSearchCV( knn_pipe, knn_grid, cv=5, scoring="accuracy", n_jobs=-1 ) lr_pipe = Pipeline([ ("scaler", StandardScaler()), ("lr", LogisticRegression(max_iter=200_000)) ]) lr_grid = { "lr__C": np.logspace(-3, 3, 50) } lr_search = GridSearchCV( lr_pipe, lr_grid, cv=5, scoring="accuracy", n_jobs=-1 )
GridSearchCV(cv=5) is the INNER CV.

KNN searches for the best n_neighbors (k). Logistic Regression searches for the best C.

The search happens only inside the current OUTER training data.
KNN

Which k works best?

Logistic Regression

Which C works best?

4. Function Inputs

def cv_report(name, model, X, y, outer_splits=5):
name

Label such as "LR".

model

Classifier, Pipeline, or GridSearchCV.

X

Features.

y

Class labels.

5. Create StratifiedKFold

outer_cv = StratifiedKFold( n_splits=outer_splits, shuffle=True, random_state=SEED )
StratifiedKFold preserves approximately the class proportions.
n_splits = number of folds.
shuffle=True = shuffle before splitting.
random_state=SEED = reproduce the same shuffle.

6. Prepare Storage and Figure

folds = [] aucs = [] plt.figure(figsize=(6,5))
folds stores each fold's metrics. aucs stores AUC values. plt.figure() creates the ROC figure.

7. Generate Fold Indices

▼ FOR LOOP STARTS HERE ▼
for fold, (train_idx, test_idx) in enumerate( outer_cv.split(X, y), 1 ): print("Running Fold:", fold)
Everything indented under this for statement runs once for each fold.

Fold 1 → run the indented code
Fold 2 → run the indented code again
Fold 3 → run it again
Fold 4 → run it again
Fold 5 → run it again
outer_cv.split(X,y) produces training and testing row indices. enumerate(...,1) numbers the folds 1–5.

Debug check: print("Running Fold:", fold) should print Fold 1, 2, 3, 4, and 5. If you only see Fold 1, the loop is not completing all five iterations.

8. Select Train and Test Rows

INSIDE THE FOR LOOP — runs once per fold
X_train, X_test = X.iloc[train_idx], X.iloc[test_idx] y_train, y_test = y.iloc[train_idx], y.iloc[test_idx]
.iloc selects rows by integer position. Four folds become training data and one fold becomes held-out test data.

9. Train the Model

INSIDE THE FOR LOOP — runs once per fold
model.fit(X_train, y_train) best_model = model.best_estimator_
model is now a GridSearchCV object. fit() runs the INNER 5-fold search using only the OUTER training set. Then best_estimator_ gives the Pipeline with the best hyperparameter.
OUTER training set
→
INNER GridSearchCV
→
best_estimator_
Do not use the OUTER test fold to choose k or C. It stays untouched until the best model has been selected.

10. Predictions

INSIDE THE FOR LOOP — runs once per fold
y_pred = best_model.predict(X_test) y_prob = best_model.predict_proba(X_test)[:, 1]
y_pred

Class labels used for Accuracy, Precision, Recall, F1.

y_prob

Probability of class 1, used for ROC/AUC.

[:,1] means all test samples, second probability column (class 1).

11. Classification Metrics

INSIDE THE FOR LOOP — runs once per fold
acc = accuracy_score(y_test, y_pred) prec = precision_score(y_test, y_pred) rec = recall_score(y_test, y_pred) f1 = f1_score(y_test, y_pred)
Accuracy

Overall correctness.

Precision

Correct among predicted positives.

Recall

Found among actual positives.

F1

Balance of precision and recall.

12. ROC and AUC

INSIDE THE FOR LOOP — runs once per fold
fpr, tpr, _ = roc_curve(y_test, y_prob) fold_auc = auc(fpr, tpr) aucs.append(fold_auc)
fpr = False Positive Rate; tpr = True Positive Rate; _ receives unused thresholds. auc() measures the area under this fold's ROC curve.

13. Plot and Save Each Fold

INSIDE THE FOR LOOP — runs once per fold
plt.plot(fpr, tpr, alpha=0.7, label=f"Fold {fold} AUC={fold_auc:.3f}") folds.append({ "Model": name, "Fold": fold, "Accuracy": acc, "Precision": prec, "Recall": rec, "F1": f1, "AUC": fold_auc, "Best Parameters": str(model.best_params_) })
Each iteration adds one ROC curve and one result dictionary. After five iterations there are five of each.
CRITICAL INDENTATION: model.fit(), predictions, metrics, roc_curve(), plt.plot(fpr,tpr,...), and folds.append(...) must all stay inside the for loop. Otherwise you may get only one ROC curve or one result row.

14. Finish the ROC Figure

▲ FOR LOOP ENDS BEFORE THIS SECTION ▲
AFTER THE FOR LOOP — runs only once, after all 5 folds finish
plt.plot([0,1], [0,1], "k--", lw=1) plt.xlabel("False Positive Rate") plt.ylabel("True Positive Rate") plt.title(f"5-Fold ROC — {name}") plt.legend(loc="lower right") plt.grid(True, alpha=0.3) plt.show()
The dashed diagonal is the random-classifier reference.
This section is OUTSIDE the for loop. The five fold curves must already have been added before plt.show() is called. Likewise, the DataFrame, Mean row, and return results belong after the loop.

15. Mean Results

AFTER THE FOR LOOP
df = pd.DataFrame(folds) mean_row = { "Model": name, "Fold": "Mean", "Accuracy": df["Accuracy"].mean(), "Precision": df["Precision"].mean(), "Recall": df["Recall"].mean(), "F1": df["F1"].mean(), "AUC": df["AUC"].mean(), "Best Parameters": "" } results = pd.concat( [df, pd.DataFrame([mean_row])], ignore_index=True ) return results
Convert the five dictionaries to a DataFrame, average each metric, append a Mean row, and return the finished table.

16. Usage Example: Load Data

from sklearn.datasets import load_breast_cancer data = load_breast_cancer(as_frame=True) X = data.data y = data.target
This step is essential: it actually creates X and y. X contains the breast-cancer features; y contains the target labels.

17. Evaluate KNN and Logistic Regression

knn_results = cv_report( "KNN", knn_search, X, y, outer_splits=5 ) lr_results = cv_report( "LR", lr_search, X, y, outer_splits=5 ) all_results = pd.concat( [knn_results, lr_results], ignore_index=True ) print(all_results)
Run the same OUTER evaluation for both GridSearchCV objects. You should get two ROC plots: one for KNN and one for Logistic Regression. Each plot contains five OUTER-fold ROC curves.

18. Python Indentation: Where the Loop Really Ends

▼ FOR LOOP STARTS HERE ▼
for fold, (train_idx, test_idx) in enumerate(outer_cv.split(X, y), 1): # INSIDE LOOP — indented X_train = X.iloc[train_idx] X_test = X.iloc[test_idx] model.fit(X_train, y_train) y_pred = best_model.predict(X_test) # calculate metrics... # calculate ROC... # plot this fold... # save this fold...
▲ FOR LOOP ENDS HERE — indentation moves back to the left ▲
These statements must NOT be indented under the loop:
# AFTER all 5 folds plt.show() df = pd.DataFrame(folds) # calculate Mean row... return results
Why your earlier code stopped after Fold 1:

return results was indented inside the for loop. Python reached it during Fold 1 and immediately left the entire function. Therefore Fold 2 never started.
return inside loop → stop after Fold 1 ❌

return after loop → finish Fold 1–5, then return ✓

Complete Executable Code

Run this complete version from top to bottom. Notice the two boundary comments: FOR LOOP STARTS HERE and FOR LOOP ENDS HERE. The ROC finishing code, mean calculation, and return results are intentionally outside the loop.
# Imports import numpy as np import pandas as pd import matplotlib.pyplot as plt from sklearn.datasets import fetch_openml from sklearn.model_selection import StratifiedKFold, GridSearchCV from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.neighbors import KNeighborsClassifier from sklearn.linear_model import LogisticRegression from sklearn.metrics import ( accuracy_score, precision_score, recall_score, f1_score, roc_curve, auc ) SEED = 42 # Load diabetes data diabetes_data = fetch_openml("diabetes", version=1, as_frame=True) X = diabetes_data.data.copy() y_raw = diabetes_data.target y = (y_raw == "tested_positive").astype(int) # Handle suspicious zeros for col in ["plas", "pres", "skin", "insu", "mass"]: X[col] = X[col].replace(0, np.nan) X[col] = X[col].fillna(X[col].median()) # KNN Pipeline + INNER GridSearchCV knn_pipe = Pipeline([ ("scaler", StandardScaler()), ("knn", KNeighborsClassifier()) ]) knn_grid = { "knn__n_neighbors": np.arange(1, 31, 2) } knn_search = GridSearchCV( knn_pipe, knn_grid, cv=5, # INNER CV scoring="accuracy", n_jobs=-1 ) # Logistic Regression Pipeline + INNER GridSearchCV lr_pipe = Pipeline([ ("scaler", StandardScaler()), ("lr", LogisticRegression(max_iter=200_000)) ]) lr_grid = { "lr__C": np.logspace(-3, 3, 50) } lr_search = GridSearchCV( lr_pipe, lr_grid, cv=5, # INNER CV scoring="accuracy", n_jobs=-1 ) def cv_report(name, model, X, y, outer_splits=5): outer_cv = StratifiedKFold( n_splits=outer_splits, shuffle=True, random_state=SEED ) folds = [] plt.figure(figsize=(6, 5)) # ========================================== # OUTER FOR LOOP STARTS HERE # ========================================== for fold, (train_idx, test_idx) in enumerate( outer_cv.split(X, y), 1 ): print("Running Outer Fold:", fold) X_train = X.iloc[train_idx] X_test = X.iloc[test_idx] y_train = y.iloc[train_idx] y_test = y.iloc[test_idx] # INNER CV: tune hyperparameters model.fit(X_train, y_train) best_model = model.best_estimator_ print("Best parameters:", model.best_params_) # OUTER test evaluation y_pred = best_model.predict(X_test) y_prob = best_model.predict_proba(X_test)[:, 1] acc = accuracy_score(y_test, y_pred) prec = precision_score(y_test, y_pred) rec = recall_score(y_test, y_pred) f1 = f1_score(y_test, y_pred) fpr, tpr, _ = roc_curve(y_test, y_prob) fold_auc = auc(fpr, tpr) plt.plot( fpr, tpr, alpha=0.7, label=f"Fold {fold} AUC={fold_auc:.3f}" ) folds.append({ "Model": name, "Fold": fold, "Accuracy": acc, "Precision": prec, "Recall": rec, "F1": f1, "AUC": fold_auc, "Best Parameters": str(model.best_params_) }) # ========================================== # OUTER FOR LOOP ENDS HERE # ========================================== plt.plot([0, 1], [0, 1], "k--", lw=1) plt.xlabel("False Positive Rate") plt.ylabel("True Positive Rate") plt.title(f"Nested 5-Fold ROC — {name}") plt.legend(loc="lower right") plt.grid(True, alpha=0.3) plt.show() df = pd.DataFrame(folds) mean_row = { "Model": name, "Fold": "Mean", "Accuracy": df["Accuracy"].mean(), "Precision": df["Precision"].mean(), "Recall": df["Recall"].mean(), "F1": df["F1"].mean(), "AUC": df["AUC"].mean(), "Best Parameters": "" } return pd.concat( [df, pd.DataFrame([mean_row])], ignore_index=True ) # Evaluate both models knn_results = cv_report( "KNN", knn_search, X, y, outer_splits=5 ) lr_results = cv_report( "LR", lr_search, X, y, outer_splits=5 ) all_results = pd.concat( [knn_results, lr_results], ignore_index=True ) print(all_results) # Compare mean AUC mean_results = all_results[all_results["Fold"] == "Mean"] best_row = mean_results.loc[mean_results["AUC"].idxmax()] print("\nBest model based on mean AUC:") print(best_row[["Model", "AUC"]])
