Random Forest in Python

Interactive, 12-step classroom walkthrough · Breast Cancer Wisconsin dataset · scikit-learn

1. Import required libraries

We use scikit-learn to train and evaluate a Random Forest, with matplotlib for visualizations.

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split, GridSearchCV, StratifiedKFold
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import (
    accuracy_score, precision_score, recall_score, f1_score,
    roc_auc_score, confusion_matrix, ConfusionMatrixDisplay,
    RocCurveDisplay, classification_report
)

2. Load the Breast Cancer Wisconsin dataset

This is the same dataset used in your Naive Bayes lesson. We use its 30 numeric tumor measurements to demonstrate Random Forest classification.

dataset = load_breast_cancer(as_frame=True)
X = dataset.data
y = dataset.target

print("Feature matrix:", X.shape)
print("Target vector:", y.shape)
print("Class labels:", list(dataset.target_names))
print("Counts:", y.value_counts().sort_index().to_dict())
print(X.head())
569 samples and 30 numeric features. Labels: 0 = malignant (212 samples); 1 = benign (357 samples). This is a teaching dataset, not a clinical diagnostic tool.
Quick check: What does X contain?

3. How Random Forest works

A Random Forest is an ensemble of decision trees. Each tree is usually trained on a bootstrap sample, and each split considers a random subset of features. The combined prediction reduces the instability of a single tree.

# Conceptual model: many decision trees vote on a class.
# In scikit-learn, RandomForestClassifier builds the trees for us.
rf_preview = RandomForestClassifier(
    n_estimators=5,
    max_features="sqrt",
    bootstrap=True,
    random_state=42
)
print(rf_preview)

4. Split training and test data

Reserve 20% of the data as a held-out test set. Stratification maintains approximately the same malignant/benign proportions in each split.

X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.20,
    random_state=42,
    stratify=y
)
print("Training samples:", len(X_train))
print("Test samples:", len(X_test))
Do not fit the model or select hyperparameters using X_test.
Train 80%
Test 20%
Quick check: Why do we hold out a test set?

5. Train a basic Random Forest

Start with a reproducible baseline before tuning the hyperparameters.

rf = RandomForestClassifier(
    n_estimators=100,
    random_state=42,
    n_jobs=-1
)
rf.fit(X_train, y_train)

print("Number of fitted trees:", len(rf.estimators_))
print("Training accuracy:", rf.score(X_train, y_train))
For a Random Forest, StandardScaler is generally unnecessary because decision trees split on feature thresholds. Training accuracy alone does not measure generalization.

6. Understand the main hyperparameters

The most useful Random Forest settings control the number of trees and how complex individual trees can become.

rf = RandomForestClassifier(
    n_estimators=200,       # Number of trees
    max_depth=10,          # Maximum tree depth
    min_samples_split=5,   # Minimum samples needed to split
    max_features="sqrt",   # Features considered at a split
    bootstrap=True,        # Resample training rows
    random_state=42,
    n_jobs=-1
)
rf.fit(X_train, y_train)
More trees often stabilize results but increase computation. Restricting depth or increasing min_samples_split can regularize the model.
Quick check: Which hyperparameter sets the number of trees?

7. Predict labels and probabilities

For each test sample, predict its class and estimate the fraction of trees supporting each class.

y_pred = rf.predict(X_test)
y_prob = rf.predict_proba(X_test)

print("Class order:", rf.classes_)
print("First 5 predicted classes:", y_pred[:5])
print("First 5 probabilities:\n", y_prob[:5])

# Probability for malignant (class 0):
malignant_index = np.where(rf.classes_ == 0)[0][0]
malignant_prob = y_prob[:, malignant_index]
The two probability columns follow rf.classes_. Because malignant is class 0, select its probability column explicitly.

8. Evaluate model performance

Evaluate the held-out predictions with accuracy, precision, recall, F1 and ROC-AUC. Here we explicitly report malignant-class metrics.

print("Accuracy:", accuracy_score(y_test, y_pred))
print("Malignant precision:", precision_score(y_test, y_pred, pos_label=0))
print("Malignant recall:", recall_score(y_test, y_pred, pos_label=0))
print("Malignant F1:", f1_score(y_test, y_pred, pos_label=0))
print("Malignant AUC:", roc_auc_score(
    (y_test == 0).astype(int), malignant_prob
))
print(classification_report(
    y_test, y_pred,
    target_names=dataset.target_names
))
The scikit-learn default positive class is 1 (benign in this dataset). Using pos_label=0 makes precision, recall, and F1 refer specifically to malignant cases.
Quick check: What does malignant recall measure?

9. Visualize the confusion matrix

Rows correspond to actual classes; columns correspond to predicted classes. Misclassifying a malignant case as benign is an especially important error to discuss.

cm = confusion_matrix(y_test, y_pred, labels=[0, 1])
print(cm)

ConfusionMatrixDisplay(
    confusion_matrix=cm,
    display_labels=dataset.target_names
).plot(cmap="Blues", values_format="d")
plt.title("Random Forest — Test Set")
plt.tight_layout()
plt.show()
With class order [malignant, benign], the upper-right cell counts malignant samples predicted benign.

10. Plot the ROC curve

The ROC curve shows sensitivity versus false-positive rate over multiple classification thresholds. We explicitly set malignant as the positive class.

RocCurveDisplay.from_predictions(
    (y_test == 0).astype(int),
    malignant_prob,
    name="Random Forest (malignant)",
)
plt.title("Random Forest ROC Curve")
plt.grid(alpha=0.3)
plt.show()
ROC-AUC summarizes discrimination across thresholds. A good AUC does not by itself establish clinical readiness.

11. Tune hyperparameters with GridSearchCV

Try combinations of tree count, depth, and splitting threshold using cross-validation on the training portion only.

param_grid = {
    "n_estimators": [50, 100, 200],
    "max_depth": [5, 10, 15, None],
    "min_samples_split": [2, 5, 10]
}

search = GridSearchCV(
    RandomForestClassifier(random_state=42, n_jobs=1),
    param_grid=param_grid,
    scoring="balanced_accuracy",
    cv=5,
    n_jobs=-1
)
search.fit(X_train, y_train)

print("Best parameters:", search.best_params_)
print("Best CV balanced accuracy:", search.best_score_)

best_rf = search.best_estimator_
print("Held-out test accuracy:", best_rf.score(X_test, y_test))
There are 3 × 4 × 3 = 36 parameter combinations, each evaluated using five training folds. balanced_accuracy averages recall over both classes. This step may take time.
Quick check: Which data is used to choose the best hyperparameters?

12. Show the top 10 feature importances

Random Forest measures impurity-based feature importance across its fitted trees. We rank the 30 original features and draw a horizontal bar chart.

importance_df_rf = pd.DataFrame({
    "Feature": X.columns,
    "Importance": best_rf.feature_importances_
}).sort_values("Importance", ascending=False)

print(importance_df_rf.head(10))

plt.figure(figsize=(10, 6))
plt.barh(
    importance_df_rf["Feature"].head(10),
    importance_df_rf["Importance"].head(10)
)
plt.xlabel("Feature Importance")
plt.ylabel("Feature")
plt.title("Top 10 Most Important Features - Random Forest")
plt.gca().invert_yaxis()
plt.tight_layout()
plt.show()
Impurity importance can favor continuous/high-cardinality features and be distorted by correlated features. It does not prove clinical causation. Compare with permutation importance for a different perspective.
