5-Fold Cross-Validation: Interactive Code Explainer

Step-by-step guided walkthrough of the simplified 5-fold Stratified Cross-Validation code.

1. Big Picture

5 stratified folds
→
Train on 4
→
Test on 1
→
Repeat ×5
Main idea: every fold is held out once. We calculate five sets of metrics and then average them.
Terminology: This lesson uses ordinary 5-fold Stratified Cross-Validation. There is no GridSearchCV, no inner CV, and no nested CV in this example.

2. Imports and SEED

import numpy as np import pandas as pd import matplotlib.pyplot as plt from sklearn.model_selection import StratifiedKFold from sklearn.metrics import ( accuracy_score, precision_score, recall_score, f1_score, roc_curve, auc ) SEED = 42
pandas builds the results table; matplotlib plots ROC curves; StratifiedKFold creates folds; metric functions evaluate predictions. SEED=42 makes shuffled splits reproducible.

3. Function Inputs

def cv5_report(name, model, X, y, n_splits=5):
name

Label such as "LR".

model

Classifier, Pipeline, or GridSearchCV.

X

Features.

y

Class labels.

4. Create StratifiedKFold

skf = StratifiedKFold( n_splits=n_splits, shuffle=True, random_state=SEED )
StratifiedKFold preserves approximately the class proportions.
n_splits = number of folds.
shuffle=True = shuffle before splitting.
random_state=SEED = reproduce the same shuffle.

5. Prepare Storage and Figure

folds = [] aucs = [] plt.figure(figsize=(6,5))
folds stores each fold's metrics. aucs stores AUC values. plt.figure() creates the ROC figure.

6. Generate Fold Indices

▼ FOR LOOP STARTS HERE ▼
for fold, (train_idx, test_idx) in enumerate( skf.split(X, y), 1 ): print("Running Fold:", fold)
Everything indented under this for statement runs once for each fold.

Fold 1 → run the indented code
Fold 2 → run the indented code again
Fold 3 → run it again
Fold 4 → run it again
Fold 5 → run it again
skf.split(X,y) produces training and testing row indices. enumerate(...,1) numbers the folds 1–5.

Debug check: print("Running Fold:", fold) should print Fold 1, 2, 3, 4, and 5. If you only see Fold 1, the loop is not completing all five iterations.

7. Select Train and Test Rows

INSIDE THE FOR LOOP — runs once per fold
X_train, X_test = X.iloc[train_idx], X.iloc[test_idx] y_train, y_test = y.iloc[train_idx], y.iloc[test_idx]
.iloc selects rows by integer position. Four folds become training data and one fold becomes held-out test data.

8. Train the Model

INSIDE THE FOR LOOP — runs once per fold
model.fit(X_train, y_train)
fit() trains the model using the current fold's training data. When the loop moves to the next fold, fit() is called again using the new training data.
X_train + y_train
→
model.fit()
→
Trained model

9. Predictions

INSIDE THE FOR LOOP — runs once per fold
y_pred = model.predict(X_test) y_prob = model.predict_proba(X_test)[:, 1]
y_pred

Class labels used for Accuracy, Precision, Recall, F1.

y_prob

Probability of class 1, used for ROC/AUC.

[:,1] means all test samples, second probability column (class 1).

10. Classification Metrics

INSIDE THE FOR LOOP — runs once per fold
acc = accuracy_score(y_test, y_pred) prec = precision_score(y_test, y_pred) rec = recall_score(y_test, y_pred) f1 = f1_score(y_test, y_pred)
Accuracy

Overall correctness.

Precision

Correct among predicted positives.

Recall

Found among actual positives.

F1

Balance of precision and recall.

11. ROC and AUC

INSIDE THE FOR LOOP — runs once per fold
fpr, tpr, _ = roc_curve(y_test, y_prob) fold_auc = auc(fpr, tpr) aucs.append(fold_auc)
fpr = False Positive Rate; tpr = True Positive Rate; _ receives unused thresholds. auc() measures the area under this fold's ROC curve.

12. Plot and Save Each Fold

INSIDE THE FOR LOOP — runs once per fold
plt.plot(fpr, tpr, alpha=0.7, label=f"Fold {fold} AUC={fold_auc:.3f}") folds.append({ "Model": name, "Fold": fold, "Accuracy": acc, "Precision": prec, "Recall": rec, "F1": f1, "AUC": fold_auc })
Each iteration adds one ROC curve and one result dictionary. After five iterations there are five of each.
CRITICAL INDENTATION: model.fit(), predictions, metrics, roc_curve(), plt.plot(fpr,tpr,...), and folds.append(...) must all stay inside the for loop. Otherwise you may get only one ROC curve or one result row.

13. Finish the ROC Figure

▲ FOR LOOP ENDS BEFORE THIS SECTION ▲
AFTER THE FOR LOOP — runs only once, after all 5 folds finish
plt.plot([0,1], [0,1], "k--", lw=1) plt.xlabel("False Positive Rate") plt.ylabel("True Positive Rate") plt.title(f"5-Fold ROC — {name}") plt.legend(loc="lower right") plt.grid(True, alpha=0.3) plt.show()
The dashed diagonal is the random-classifier reference.
This section is OUTSIDE the for loop. The five fold curves must already have been added before plt.show() is called. Likewise, the DataFrame, Mean row, and return results belong after the loop.

14. Mean Results

AFTER THE FOR LOOP
df = pd.DataFrame(folds) mean_row = { "Model": name, "Fold": "Mean", "Accuracy": df["Accuracy"].mean(), "Precision": df["Precision"].mean(), "Recall": df["Recall"].mean(), "F1": df["F1"].mean(), "AUC": df["AUC"].mean() } results = pd.concat( [df, pd.DataFrame([mean_row])], ignore_index=True ) return results
Convert the five dictionaries to a DataFrame, average each metric, append a Mean row, and return the finished table.

15. Usage Example: Load Data

from sklearn.datasets import load_breast_cancer data = load_breast_cancer(as_frame=True) X = data.data y = data.target
This step is essential: it actually creates X and y. X contains the breast-cancer features; y contains the target labels.

16. Usage Example: Create the Model

from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.linear_model import LogisticRegression lr = Pipeline([ ("scaler", StandardScaler()), ("lr", LogisticRegression(max_iter=5000)) ])
The Pipeline scales the features and then fits Logistic Regression. This lr object is a plain Pipeline, not GridSearchCV.

17. Call the Function

results = cv5_report( "LR", lr, X, y, n_splits=5 ) print(results)
"LR"
→ name
lr
→ model
X
→ features
y
→ labels
Defining cv5_report() does not run it. This call executes the five-fold evaluation and stores the returned DataFrame in results.

18. Python Indentation: Where the Loop Really Ends

▼ FOR LOOP STARTS HERE ▼
for fold, (train_idx, test_idx) in enumerate(skf.split(X, y), 1): # INSIDE LOOP — indented X_train = X.iloc[train_idx] X_test = X.iloc[test_idx] model.fit(X_train, y_train) y_pred = model.predict(X_test) # calculate metrics... # calculate ROC... # plot this fold... # save this fold...
▲ FOR LOOP ENDS HERE — indentation moves back to the left ▲
These statements must NOT be indented under the loop:
# AFTER all 5 folds plt.show() df = pd.DataFrame(folds) # calculate Mean row... return results
Why your earlier code stopped after Fold 1:

return results was indented inside the for loop. Python reached it during Fold 1 and immediately left the entire function. Therefore Fold 2 never started.
return inside loop → stop after Fold 1 ❌

return after loop → finish Fold 1–5, then return ✓

Complete idea: Load the data → create the Logistic Regression Pipeline → create five stratified folds → train and test five times → calculate metrics and ROC curves → average the five fold results.

Indentation map:

Complete Executable Code

Run this complete version from top to bottom. Notice the two boundary comments: FOR LOOP STARTS HERE and FOR LOOP ENDS HERE. The ROC finishing code, mean calculation, and return results are intentionally outside the loop.
# Minimal imports import numpy as np import pandas as pd import matplotlib.pyplot as plt from sklearn.model_selection import StratifiedKFold from sklearn.metrics import ( accuracy_score, precision_score, recall_score, f1_score, roc_curve, auc ) SEED = 42 def cv5_report(name, model, X, y, n_splits=5): # Create stratified folds skf = StratifiedKFold( n_splits=n_splits, shuffle=True, random_state=SEED ) folds = [] # Create one ROC figure plt.figure(figsize=(6, 5)) # ========================================== # FOR LOOP STARTS HERE # ========================================== for fold, (train_idx, test_idx) in enumerate( skf.split(X, y), 1 ): print("Running Fold:", fold) # 1. Select training and test data X_train = X.iloc[train_idx] X_test = X.iloc[test_idx] y_train = y.iloc[train_idx] y_test = y.iloc[test_idx] # 2. Train the model model.fit(X_train, y_train) # 3. Make predictions y_pred = model.predict(X_test) y_prob = model.predict_proba(X_test)[:, 1] # 4. Calculate classification metrics acc = accuracy_score(y_test, y_pred) prec = precision_score(y_test, y_pred) rec = recall_score(y_test, y_pred) f1 = f1_score(y_test, y_pred) # 5. Calculate ROC and AUC fpr, tpr, _ = roc_curve(y_test, y_prob) fold_auc = auc(fpr, tpr) # 6. Plot this fold's ROC curve plt.plot( fpr, tpr, alpha=0.7, label=f"Fold {fold} AUC={fold_auc:.3f}" ) # 7. Save this fold's results folds.append({ "Model": name, "Fold": fold, "Accuracy": acc, "Precision": prec, "Recall": rec, "F1": f1, "AUC": fold_auc }) # ========================================== # FOR LOOP ENDS HERE # ========================================== # Finish ROC plot AFTER all 5 folds plt.plot([0, 1], [0, 1], "k--", lw=1) plt.xlabel("False Positive Rate") plt.ylabel("True Positive Rate") plt.title(f"5-Fold ROC — {name}") plt.legend(loc="lower right") plt.grid(True, alpha=0.3) plt.show() # Convert fold results to a DataFrame df = pd.DataFrame(folds) # Calculate mean performance mean_row = { "Model": name, "Fold": "Mean", "Accuracy": df["Accuracy"].mean(), "Precision": df["Precision"].mean(), "Recall": df["Recall"].mean(), "F1": df["F1"].mean(), "AUC": df["AUC"].mean() } # Add Mean row results = pd.concat( [df, pd.DataFrame([mean_row])], ignore_index=True ) # Return only AFTER all folds are finished return results # ============================================== # EXAMPLE: LOAD DATA # ============================================== from sklearn.datasets import load_breast_cancer data = load_breast_cancer(as_frame=True) X = data.data y = data.target # ============================================== # CREATE LOGISTIC REGRESSION PIPELINE # ============================================== from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.linear_model import LogisticRegression lr = Pipeline([ ("scaler", StandardScaler()), ("lr", LogisticRegression(max_iter=5000)) ]) # ============================================== # CALL THE FUNCTION # ============================================== results = cv5_report( "LR", lr, X, y, n_splits=5 ) print(results)
