Support Vector Machine (SVM) in Python: Grid Search Workflow

9-step interactive walkthrough. Learn the SVM idea first, then use GridSearchCV to select the best SVM hyperparameters using the training data.

1. Import Required Libraries

import numpy as np import matplotlib.pyplot as plt from sklearn.datasets import load_breast_cancer from sklearn.model_selection import train_test_split, GridSearchCV from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.svm import SVC from sklearn.metrics import ( accuracy_score, precision_score, recall_score, f1_score, confusion_matrix, ConfusionMatrixDisplay, classification_report )
Goal: load a classification dataset, split it, scale the features, create an SVM, use GridSearchCV to choose SVM hyperparameters, predict the test data, and evaluate the final model.

2. Load the Breast Cancer Dataset

data = load_breast_cancer() X = data.data y = data.target print("X shape:", X.shape) print("y shape:", y.shape) print(data.feature_names) print(data.target_names)
X contains 30 numeric features. y contains class labels: 0 = malignant and 1 = benign.

3. Split into Training and Test Sets

X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.20, random_state=42, stratify=y ) print(X_train.shape, X_test.shape)
TRAIN 80%
TEST 20%
stratify=y preserves approximately the original class proportions in both sets. The test set stays untouched while GridSearchCV works on the training set.

4. Understand the SVM Idea

SVM finds a decision boundary that separates classes while maximizing the margin.
Hyperplane

The decision boundary. In two dimensions, it is a line.

Margin

The space between the boundary and the nearest training observations.

Support Vectors

The observations closest to the boundary. They are especially important for determining it.

Kernel

Allows SVM to create nonlinear boundaries when a straight boundary is not enough.

Class 0   ← margin →   Decision Boundary   ← margin →   Class 1

Wider margin is generally preferred.

5. Create the SVM Pipeline

z = (x − μ) / σ
svm_pipe = Pipeline([ ("scaler", StandardScaler()), ("svm", SVC(probability=True)) ])
Why scale? SVM is sensitive to feature scale. StandardScaler() puts features on comparable scales. Keeping the scaler inside the pipeline also prevents data leakage during cross-validation.

Why probability=True? It allows probability estimates later if you want ROC/AUC analysis.

6. Use Grid Search to Find the Best SVM Model

C: Small C allows more training errors and encourages a wider/softer margin. Large C penalizes errors more strongly.

kernel: linear uses a linear boundary; rbf can create nonlinear boundaries.

gamma: for RBF, smaller gamma gives broader influence and a smoother boundary; larger gamma gives more local influence and potentially a more complex boundary.
param_grid = { "svm__C": [0.01, 0.1, 1, 10, 100], "svm__kernel": ["linear", "rbf"], "svm__gamma": ["scale", "auto"] } grid = GridSearchCV( svm_pipe, param_grid, cv=5, scoring="accuracy", n_jobs=-1 ) grid.fit(X_train, y_train) print("Best parameters:", grid.best_params_) print("Best CV accuracy:", grid.best_score_) best_model = grid.best_estimator_
GridSearchCV tries the SVM hyperparameter combinations using 5-fold CV on the training set only. The test set is not used to choose C, kernel, or gamma.

7. Make Predictions with the Best Model

y_pred = best_model.predict(X_test) print("First 10 predictions:", y_pred[:10]) print("First 10 actual labels:", y_test[:10])
After GridSearchCV selects the best SVM, we finally apply it to X_test. This is the first time the held-out test set is used for model evaluation.

8. Evaluate the SVM

accuracy = accuracy_score(y_test, y_pred) precision = precision_score(y_test, y_pred) recall = recall_score(y_test, y_pred) f1 = f1_score(y_test, y_pred) tn, fp, fn, tp = confusion_matrix(y_test, y_pred).ravel() specificity = tn / (tn + fp) print(f"Accuracy: {accuracy:.4f}") print(f"Precision: {precision:.4f}") print(f"Recall: {recall:.4f}") print(f"Specificity: {specificity:.4f}") print(f"F1 Score: {f1:.4f}") print("\nClassification Report:") print(classification_report( y_test, y_pred, target_names=data.target_names ))

Important: this dataset uses 1 = benign, so the default precision and recall describe the benign class. The classification report gives metrics for both classes.

Complete Executable Code

import numpy as np import matplotlib.pyplot as plt from sklearn.datasets import load_breast_cancer from sklearn.model_selection import train_test_split, GridSearchCV from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.svm import SVC from sklearn.metrics import ( accuracy_score, precision_score, recall_score, f1_score, confusion_matrix, ConfusionMatrixDisplay, classification_report ) data = load_breast_cancer() X = data.data y = data.target X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.20, random_state=42, stratify=y ) svm_pipe = Pipeline([ ("scaler", StandardScaler()), ("svm", SVC(probability=True)) ]) param_grid = { "svm__C": [0.01, 0.1, 1, 10, 100], "svm__kernel": ["linear", "rbf"], "svm__gamma": ["scale", "auto"] } grid = GridSearchCV( svm_pipe, param_grid, cv=5, scoring="accuracy", n_jobs=-1 ) grid.fit(X_train, y_train) print("Best parameters:", grid.best_params_) print("Best CV accuracy:", grid.best_score_) best_model = grid.best_estimator_ y_pred = best_model.predict(X_test) accuracy = accuracy_score(y_test, y_pred) precision = precision_score(y_test, y_pred) recall = recall_score(y_test, y_pred) f1 = f1_score(y_test, y_pred) tn, fp, fn, tp = confusion_matrix(y_test, y_pred).ravel() specificity = tn / (tn + fp) print(f"Accuracy: {accuracy:.4f}") print(f"Precision: {precision:.4f}") print(f"Recall: {recall:.4f}") print(f"Specificity: {specificity:.4f}") print(f"F1 Score: {f1:.4f}") print("\nClassification Report:") print(classification_report( y_test, y_pred, target_names=data.target_names )) cm = confusion_matrix(y_test, y_pred) disp = ConfusionMatrixDisplay( confusion_matrix=cm, display_labels=data.target_names ) disp.plot(cmap="Blues", values_format="d") plt.title("Best SVM Model - Confusion Matrix") plt.show()
