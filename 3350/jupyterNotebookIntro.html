Jupyter Notebook — Quickstart Page

1) What is Jupyter Notebook?

Jupyter Notebook is an interactive programming environment that allows you to write and run code in small sections called cells.

Instead of writing an entire Python program and running everything at once, Jupyter allows you to run your program one piece at a time and immediately see the result.

A Jupyter Notebook can contain:

  • Python code
  • Program output
  • Text explanations
  • Mathematical equations
  • Tables
  • Graphs and visualizations
  • Images
Think of Jupyter Notebook as an interactive digital notebook where code, explanations, and results can all appear together.

2) Why Use Jupyter Notebook?

Jupyter Notebook is especially useful for data science, machine learning, scientific computing, and learning Python.

  • Interactive programming: Run one piece of code at a time.
  • Immediate results: See output directly below your code.
  • Easy debugging: Test small parts of your program individually.
  • Data visualization: Display charts directly inside the notebook.
  • Documentation: Add explanations using Markdown cells.
  • Good for experiments: Try different ideas without repeatedly running an entire program.

3) Main Components of a Jupyter Notebook

A Jupyter Notebook file normally has the extension: 

.ipynb

A notebook is made of individual cells. The two most common cell types are:

  • Code cells — contain Python code.
  • Markdown cells — contain explanations and formatted text.

Example Notebook Structure

Markdown Cell:
Introduction to Python Lists

Code Cell:
numbers = [10, 20, 30, 40]

Code Cell:
print(numbers)

Output:
[10, 20, 30, 40]

4) Code Cells and Markdown Cells

Code Cell

A Code cell contains executable Python code. 

        
        
          x = 10
          y = 20
          x + y

The output appears directly below the cell:

30

Markdown Cell

A Markdown cell contains formatted text instead of executable Python code.

For example:

        
        # Introduction

This notebook demonstrates **Python programming**.

## Topics

- Variables
- Lists
- Loops
- Functions

Markdown is useful for explaining what your code does.

5) How to Launch Jupyter Notebook

If you installed Anaconda, Jupyter Notebook is usually already installed.

Option 1 — Using Anaconda Navigator

  1. Open Anaconda Navigator.
  2. Find Jupyter Notebook.
  3. Click Launch.
  4. Your web browser will open the Jupyter interface.

Option 2 — Using Anaconda Prompt or Terminal

        
        jupyter notebook

Jupyter will normally open automatically in your web browser.

JupyterLab

You can also launch the newer Jupyter interface called JupyterLab. 

        
        jupyter lab

6) Your First Jupyter Notebook Example

Create a new Python notebook and enter the following code into the first cell. 

        
        print("Hello, Jupyter Notebook!")

Press: 

Shift + Enter

The cell will run and display: 

Hello, Jupyter Notebook!

Another Example

        
        x = 5
y = 8

result = x + y

print(result)

Output:

13

7) Basic Jupyter Notebook Workflow

A typical Jupyter Notebook workflow looks like this:

  1. Start Jupyter Notebook.
  2. Create a new notebook.
  3. Write Python code in a Code cell.
  4. Press Shift + Enter to run the cell.
  5. Examine the output.
  6. Add another cell and continue your analysis.
  7. Add Markdown cells to explain your work.
  8. Save the notebook.
Jupyter remembers variables that have already been created while the notebook kernel is running.

8) Useful Keyboard Shortcuts

These shortcuts can make working in Jupyter much faster.

  • Shift + Enter — Run the current cell and move to the next cell.
  • Ctrl + Enter — Run the current cell and stay in the same cell.
  • Alt + Enter — Run the current cell and create a new cell below it.
  • A — Insert a cell above the current cell (Command Mode).
  • B — Insert a cell below the current cell (Command Mode).
  • DD — Delete the selected cell (press D twice).
  • M — Change the selected cell to Markdown.
  • Y — Change the selected cell to Code.
