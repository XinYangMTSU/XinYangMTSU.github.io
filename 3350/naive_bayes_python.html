Naive Bayes (GaussianNB) in Python

Interactive, 9-step classroom walkthrough · Breast Cancer Wisconsin dataset · scikit-learn

1. Import required libraries

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.naive_bayes import GaussianNB
from sklearn.metrics import (
    accuracy_score, precision_score, recall_score, f1_score,
    confusion_matrix, ConfusionMatrixDisplay, classification_report,
    roc_auc_score
)
We use GaussianNB because the dataset contains continuous numerical measurements. Unlike the decision tree, Naive Bayes models each feature’s distribution within each class.

2. Load the breast cancer dataset

data = load_breast_cancer()
X = data.data
y = data.target

print("X shape:", X.shape)
print("y shape:", y.shape)
print("Classes:", data.target_names)
print("Class counts [malignant, benign]:", np.bincount(y))
print("First five features:", data.feature_names[:5])
The dataset contains 569 samples, 30 continuous features, and two classes: 0 = malignant (212), 1 = benign (357). This is a classroom dataset—not a clinical diagnostic tool.

3. Split the data: 80% training / 20% testing

X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.20,
    random_state=42,
    stratify=y
)

print("Training:", X_train.shape)
print("Testing:", X_test.shape)
stratify=y preserves approximately the original class percentages in both sets. Do not train or tune using the test set.

Test 20%

4. Understand the Naive Bayes rule

# Conceptual example: score each class using
# prior probability × feature likelihoods.
# GaussianNB estimates likelihoods with Gaussian curves.

print("Naive Bayes assumption:")
print("Features are independent GIVEN the class.")
Prior = how common the class is. Likelihood = how likely the feature values are within that class. Multiply these terms to get an unnormalized class score. The denominator is common across classes; normalize scores to obtain posterior probabilities. For continuous features, GaussianNB uses probability densities, not the probabilities of exact values.
P(Ck | x) ∝ P(Ck) ∏i=1n P(xi | Ck)Class score = Prior × Feature 1 likelihood × Feature 2 likelihood × …

For Gaussian Naive Bayes, feature likelihoods come from class-specific normal probability density functions. The symbol ∝ means “proportional to.”

Quick check: What is the ‘naive’ assumption?

5. Create and train Gaussian Naive Bayes

nb = GaussianNB()
nb.fit(X_train, y_train)

print("Learned class order:", nb.classes_)
print("Learned class priors:", nb.class_prior_)
print("Training accuracy:", nb.score(X_train, y_train))
fit() estimates a mean and variance for each feature in each class. class_prior_ shows the class proportions from training data. A standard GaussianNB model does not require StandardScaler, though transformations can matter for some variants and numerical settings.
Quick check: What does GaussianNB learn for each continuous feature in each class?

6. Predict classes and probabilities

y_pred = nb.predict(X_test)
y_proba = nb.predict_proba(X_test)

print("First 5 predicted labels:", y_pred[:5])
print("First 5 actual labels:", y_test[:5])
print("Probability columns:", nb.classes_)
print("First 5 posterior probabilities:\n", y_proba[:5])
predict() returns class labels; predict_proba() returns a probability for each class. Always inspect nb.classes_ to identify the correct columns. In this dataset label 0 is malignant, not benign.

9. Optional: tune var_smoothing using cross-validation

param_grid = {"var_smoothing": np.logspace(-12, -6, 7)}
search = GridSearchCV(
    GaussianNB(),
    param_grid=param_grid,
    cv=5,
    scoring="balanced_accuracy",
    n_jobs=-1
)
search.fit(X_train, y_train)

print("Best parameters:", search.best_params_)
print("Best CV balanced accuracy:", search.best_score_)

best_nb = search.best_estimator_
print("Tuned test accuracy:", best_nb.score(X_test, y_test))
var_smoothing adds a small stabilization term to the estimated variances. GridSearchCV uses training data only for model selection. The held-out test set is used once at the end. There is no need to scale features for this basic lesson.
