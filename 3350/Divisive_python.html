Divisive (Top-Down) Clustering in Python

8-step interactive walkthrough • Euclidean distance • largest-diameter splitting • farthest-pair seeds

1. Define the Data

Start with one cluster containing all five points.

import numpy as np
X = np.array([[2,3],[2,5],[5,3],[6,7],[8,6]])
labels = ["P1", "P2", "P3", "P4", "P5"]
C0 = {P1,P2,P3,P4,P5}

2. Pairwise Euclidean Distances

d(A,B) = √((xA−xB)² + (yA−yB)²)

from scipy.spatial.distance import pdist, squareform
D = squareform(pdist(X, metric="euclidean"))
print(np.round(D,2))
Diameter of C0 = 6.71, between P1 and P5.

Which pair is farthest?

3. Split 1: Farthest Seeds

Seeds P1 and P5. Assign remaining points to the nearest seed.

Python: define the diameter and farthest-seed split functions, then try the first split.

def diameter(cluster):
    if len(cluster) < 2:
        return 0.0
    return max(D[i, j] for i in cluster for j in cluster)

def split_cluster(cluster):
    # Choose the farthest two points as seeds
    a, b = max(
        ((i, j) for i in cluster for j in cluster if i < j),
        key=lambda pair: D[pair[0], pair[1]]
    )
    left, right = [a], [b]
    for i in cluster:
        if i not in (a, b):
            (left if D[i, a] <= D[i, b] else right).append(i)
    return sorted(left), sorted(right)

# Demonstrate the first split
print(split_cluster(list(range(5))))  # ([0, 1, 2], [3, 4])
At 6.71: {P1,P2,P3} | {P4,P5}

4. Split 2: Largest Diameter

diam({P1,P2,P3}) = 3.61; diam({P4,P5}) = 2.24. Split the first cluster using seeds P2 and P3; P1 joins P2.

Python: run the top-down loop. The first two iterations correspond to Splits 1 and 2.

# Automatically repeat the largest-diameter split
clusters = [list(range(len(X)))]
history = [[c.copy() for c in clusters]]
splits = []

while any(len(c) > 1 for c in clusters):
    target = max((c for c in clusters if len(c) > 1),
                 key=diameter)
    height = diameter(target)
    left, right = split_cluster(target)
    splits.append((tuple(target), tuple(left),
                   tuple(right), height))
    clusters.remove(target)
    clusters.extend([left, right])
    history.append([c.copy() for c in clusters])
    print(f"Height {height:.2f}:",
          [labels[i] for i in left], "|",
          [labels[i] for i in right])
At 3.61: {P1,P2} | {P3} | {P4,P5}

Why split {P1,P2,P3}?

5. Final Two Splits

Split 3 at 2.24

{P4,P5} → {P4} | {P5}

Split 4 at 2.00

{P1,P2} → {P1} | {P2}

All five points are now singleton clusters.

Python: inspect the final two splits and all intermediate clusters.

# Inspect the full split history from the previous step
for step, groups in enumerate(history):
    print(f"After {step} split(s):",
          [[labels[i] for i in c] for c in groups])

6. Dendrogram

import matplotlib.pyplot as plt
from scipy.cluster.hierarchy import dendrogram

# Rebuild the divisive tree in SciPy linkage format
ids = {(i,): i for i in range(len(X))}
Z = []
for parent, left, right, height in reversed(splits):
    Z.append([ids[tuple(sorted(left))],
              ids[tuple(sorted(right))], height, len(parent)])
    ids[tuple(sorted(parent))] = len(X) + len(Z) - 1

Z = np.array(Z, dtype=float)
plt.figure(figsize=(8, 5))
dendrogram(Z, labels=labels)
plt.ylabel("Cluster diameter at split")
plt.title("Top-Down Divisive Clustering")
plt.tight_layout()
plt.show()
Heights represent the diameter at each divisive split, not an agglomerative linkage fit.

7. Explore Dendrogram Cuts

At height 2.5, which point becomes a singleton?

Python: inspect the two requested cuts without rerunning the clustering.

# Cut at selected heights (strictly below split heights)
for cut in [4.0, 2.5]:
    groups = [list(range(len(X)))]
    for parent, left, right, height in splits:
        if height <= cut:
            continue
        # Only split a parent that is still present
        if list(parent) in groups:
            groups.remove(list(parent))
            groups.extend([list(left), list(right)])
    print(f"Cut {cut}:",
          [[labels[i] for i in c] for c in groups])

8. Review the Step-by-Step Workflow

The Python code is now distributed across Steps 1–7. Run each code block in order in one notebook or Python session—no long code dump is needed here.

Run in order: 1. Data → 2. Distances → 3. Split functions → 4. Recursive splitting → 5. Inspect history → 6. Dendrogram → 7. Cut heights.
Key idea: Start together → choose cluster of largest diameter → farthest-pair seeds → assign to nearest seed → repeat. This is a DIANA-style heuristic, not the original DIANA algorithm.
