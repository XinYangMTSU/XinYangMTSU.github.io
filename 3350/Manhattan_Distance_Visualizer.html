About Manhattan Distance

Manhattan distance is the distance between two points measured by moving only along coordinate axes—like traveling through a city laid out in rectangular blocks. It is also called city-block distance, taxicab distance, or L1 distance.

d₁(x, x′) = Σ |xⱼ − x′ⱼ|

2D: d₁(A,B) = |x₂ − x₁| + |y₂ − y₁|

Real-Life Applications

  • City navigation: distance traveled along streets in a grid-like city, where movement follows horizontal and vertical directions rather than a straight line.
  • Grid-based robotics and path planning: useful when a robot or agent can move along fixed horizontal and vertical directions rather than moving directly between two points.
  • Machine learning: Manhattan distance is an alternative to Euclidean distance for measuring similarity between observations. It adds the absolute differences between corresponding features rather than using squared differences.

Important intuition: Manhattan distance adds absolute differences rather than squaring them. Therefore, large individual feature differences are not emphasized as strongly as they are with Euclidean distance.

Feature scaling matters: if one feature has a much larger numerical scale than another, it can still dominate the Manhattan distance.

How is it different from Euclidean Distance?

For A=(1,1) and B=(4,5), Manhattan distance is 3 + 4 = 7, while Euclidean distance is 5. Euclidean distance travels directly between the points; Manhattan distance adds movement along each coordinate direction.
