Ridge Regression: Pipeline + GridSearchCV

Interactive walkthrough of the complete Python demo. Every code block is complete code for that step and can be copied into a notebook in order.

1. Import Libraries and Load the Dataset

Before using the classes and functions in this demo, import all required libraries:

import numpy as np from sklearn.datasets import load_diabetes from sklearn.model_selection import train_test_split, GridSearchCV from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.linear_model import Ridge from sklearn.metrics import ( mean_squared_error, root_mean_squared_error, r2_score )
What are these imports for?

numpy → numerical operations
load_diabetes → load the example dataset
train_test_split → create training and test sets
GridSearchCV → search for the best alpha using cross-validation
Pipeline → connect preprocessing and Ridge into one workflow
StandardScaler → standardize the input features
Ridge → Ridge regression model
mean_squared_error, root_mean_squared_error, r2_score → evaluate model performance

Now load the data

data = load_diabetes() X = data.data y = data.target print("X shape:", X.shape) print("y shape:", y.shape) print("Feature names:", data.feature_names)
X contains 442 observations and 10 input features. y is the quantitative diabetes disease-progression target. First identify what the model receives and what it predicts.

2. Create train/test data

X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.20, random_state=42 ) print("\nTraining samples:", X_train.shape[0]) print("Test samples:", X_test.shape[0])
TRAIN 80%
TEST 20%
GridSearchCV uses the training data only. The test set stays untouched until final evaluation.

3. Build the Pipeline

ridge_pipe = Pipeline([ ("scaler", StandardScaler()), ("ridge", Ridge()) ])
CV training fold→fit scaler→transform→fit Ridge
Putting StandardScaler inside the Pipeline makes CV refit the scaler separately using only each fold's training portion, preventing validation-fold leakage.

4. Define candidate α values

ridge_grid = { "ridge__alpha": [0.01, 0.1, 1, 10, 100] }
ridge__alpha means “the alpha parameter inside the Pipeline step named ridge.” Small α = weaker regularization; large α = stronger regularization.

5. Configure GridSearchCV

ridge_search = GridSearchCV( estimator=ridge_pipe, param_grid=ridge_grid, cv=5, scoring="neg_mean_squared_error", n_jobs=-1, return_train_score=True )
ParameterMeaning
estimatorScaler → Ridge Pipeline
param_gridα values to try
cv=55-fold CV
scoringcompare validation MSE
n_jobs=-1use all available CPU cores
return_train_scorealso store CV training scores
This configures the experiment. .fit() actually runs it.

6. Run .fit(): see one 5-fold CV

ridge_search.fit(X_train, y_train)
Fold 1
Fold 2
Fold 3
Fold 4
Fold 5

For one α: train on 4 folds, validate on 1; repeat five times.

With 5 α values × 5 folds, GridSearchCV performs 25 CV fits, followed by the default refit of the best pipeline on all training data.

7. Why negative MSE?

scikit-learn scorers use “higher is better.” Negating MSE converts a minimization metric into that convention. The actual MSE itself is not negative.

8. Compare α Values

This is the complete Python code used to display the cross-validation result for every alpha:

print("\nCross-Validation Results") print("------------------------") for alpha, score in zip( ridge_search.cv_results_["param_ridge__alpha"], ridge_search.cv_results_["mean_test_score"], ): mse = -score print( f"alpha = {float(alpha):7.2f} " f"Average CV MSE = {mse:.4f}" )

9. Select the best α

best_alpha = ridge_search.best_params_["ridge__alpha"] best_cv_mse = -ridge_search.best_score_ print("\nBest alpha:", best_alpha) print(f"Best CV MSE: {best_cv_mse:.4f}")

10. Refit the best Pipeline

best_ridge = ridge_search.best_estimator_
ALL X_train→fit scaler→Ridge(best α)
GridSearchCV uses refit=True by default. After choosing α, it refits the complete best Pipeline on all training data.

11. Predict and Evaluate

Use the refitted best pipeline to make predictions:

y_train_pred = best_ridge.predict(X_train) y_test_pred = best_ridge.predict(X_test)

Now calculate the evaluation metrics:

train_mse = mean_squared_error( y_train, y_train_pred ) test_mse = mean_squared_error( y_test, y_test_pred ) train_rmse = root_mean_squared_error( y_train, y_train_pred ) test_rmse = root_mean_squared_error( y_test, y_test_pred ) train_r2 = r2_score( y_train, y_train_pred ) test_r2 = r2_score( y_test, y_test_pred ) print("\nRidge Regression Results") print("------------------------") print(f"Train MSE: {train_mse:.4f}") print(f"Test MSE: {test_mse:.4f}") print(f"Train RMSE: {train_rmse:.4f}") print(f"Test RMSE: {test_rmse:.4f}") print(f"Train R²: {train_r2:.4f}") print(f"Test R²: {test_r2:.4f}")
MSE/RMSE: lower is better. R²: generally higher is better. CV selected α; the untouched test set now evaluates the selected workflow.

12. Inspect Ridge Coefficients

ridge_model = best_ridge.named_steps["ridge"] print("\nRidge coefficients") print("------------------") for feature, coef in zip( data.feature_names, ridge_model.coef_ ): print(f"{feature:8s}: {coef:10.4f}")
Complete story: Load → split → Pipeline → α grid → GridSearchCV → fold-specific scaling → choose α → refit all training data → predict test → evaluate → inspect coefficients.
