K-Nearest Neighbors (KNN) Explained

Explore how KNN predicts from local neighborhoods. Change k, the distance metric, voting rule, and the new point.

1) The Big Idea

Non-parametric

No fixed functional form for the decision boundary and no fixed set of learned coefficients.

Instance-based

Stores training examples and compares new inputs directly with them.

Classification: vote among the k nearest labels.
Regression: average the k nearest numeric targets.
New point → find k nearest samples → aggregate targets → prediction

3) What does k do?

Small k

  • Low bias
  • High variance
  • Sensitive to noise
  • Very local

Large k

  • Higher bias
  • Lower variance
  • Smoother prediction
  • May hide local structure
Treat k as a hyperparameter; choose it using validation/cross-validation.

4) Distance Metrics

Minkowski: d(x,z)=(Σ|xⱼ−zⱼ|ᵖ)1/p

Euclidean, p=2

√[(x₁−z₁)²+(x₂−z₂)²]

Manhattan, p=1

|x₁−z₁|+|x₂−z₂|

Chebyshev, p→∞

max(|x₁−z₁|,|x₂−z₂|)

Explore

Changing the metric can change which points are nearest.

5) Feature Scaling Is Essential

Problem

If Age is 18–70 but Income is 20,000–200,000, income can dominate the distance.

Standardization

z=(x−μ)/σ

Put numeric features on comparable scales.

Important: KNN uses distance directly, so scale/standardize features when appropriate.

6) Uniform vs. Distance-Weighted

Uniform

Every selected neighbor gets one equal vote.

Distance-weighted

Closer neighbors get more influence, often using weight ≈ 1/distance.

8) Choosing k

A common workflow is grid search + cross-validation over k, distance metric, and weighting.

9) Curse of Dimensionality

As dimension grows, data become sparse and distances can become less informative. Irrelevant features can also distort neighborhoods.
