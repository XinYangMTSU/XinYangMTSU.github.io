Decision Tree (CART) in Python

Interactive, 9-step classroom walkthrough · Breast Cancer Wisconsin dataset · scikit-learn

1. Import libraries

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.tree import DecisionTreeClassifier, plot_tree, export_text
from sklearn.metrics import (
    accuracy_score, precision_score, recall_score, f1_score,
    confusion_matrix, ConfusionMatrixDisplay, classification_report
)
Teaching note: We will use scikit-learn for classification, matplotlib for the tree and confusion matrix, and NumPy for arrays.

2. Load the breast cancer dataset

data = load_breast_cancer()
X = data.data
y = data.target

print("Feature matrix:", X.shape)
print("Labels:", y.shape)
print("Classes:", data.target_names)
print("First five features:", data.feature_names[:5])
print("Class counts:", np.bincount(y))
Teaching note: There are 569 samples and 30 numeric features. Labels are 0 = malignant (212 cases) and 1 = benign (357 cases). This is a teaching dataset, not a clinical decision tool.

3. Split the data (80% train / 20% test)

X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.20,
    random_state=42,
    stratify=y
)
print("Training:", X_train.shape)
print("Testing:", X_test.shape)
Teaching note: The test set is held out until the final evaluation. stratify=y preserves approximately the same malignant/benign proportions in each set.
Train 80%
Test 20%
Quick check: Why use stratify=y?

4. Create the decision tree

tree = DecisionTreeClassifier(
    criterion="gini",
    max_depth=3,
    random_state=42
)
print(tree)
Teaching note: CART uses binary questions such as “feature ≤ threshold?” At each node, sklearn chooses the split with the largest impurity reduction. max_depth=3 makes the first tree easier to inspect. Unlike KNN, a standard decision tree does not need feature scaling.
Gini impurity: G = 1 − Σ pᵢ². For example, if 60% of cases are one class and 40% the other, G = 1 − (0.6² + 0.4²) = 0.48. The maximum for two classes is 0.5.
Quick check: Does a standard CART tree require StandardScaler?

5. Train the classifier

tree.fit(X_train, y_train)
print("Training accuracy:", tree.score(X_train, y_train))
print("Depth:", tree.get_depth())
print("Leaves:", tree.get_n_leaves())
Teaching note: fit() learns both the features and thresholds used at each split. Training accuracy measures performance on the data used to build the tree; it is not an unbiased estimate of generalization.

6. Visualize and interpret the tree

plt.figure(figsize=(18, 9))
plot_tree(
    tree,
    feature_names=data.feature_names,
    class_names=data.target_names,
    filled=True,
    rounded=True,
    fontsize=9
)
plt.title("Decision Tree — max_depth=3 (training set)")
plt.tight_layout()
plt.show()

print(export_text(tree, feature_names=list(data.feature_names)))
Teaching note: In a node, “samples” counts training examples reaching that node; “value” lists [malignant, benign] because those are the dataset class orders. Left branch = condition true (≤ threshold), right branch = false (> threshold). The original attached illustration uses manually typed counts that are not all internally consistent, so this plot generates correct counts directly from the fitted model.

Quick check: What does Gini impurity = 0 indicate?

7. Make predictions on held-out data

y_pred = tree.predict(X_test)

print("Predictions:", y_pred[:10])
print("Actual:", y_test[:10])
Teaching note: predict() follows the learned threshold rules until each sample reaches a leaf. Each leaf predicts its majority class. The test set has not been used to select the rules.

8. Evaluate model performance

print("Accuracy:", accuracy_score(y_test, y_pred))
print("\nClassification report:\n")
print(classification_report(y_test, y_pred, target_names=data.target_names))

# Set malignant (label 0) as the positive class for this example.
print("Malignant precision:", precision_score(y_test, y_pred, pos_label=0))
print("Malignant recall:", recall_score(y_test, y_pred, pos_label=0))
print("Malignant F1:", f1_score(y_test, y_pred, pos_label=0))

cm = confusion_matrix(y_test, y_pred, labels=[0, 1])
print("Confusion matrix [malignant, benign]:\n", cm)
ConfusionMatrixDisplay(cm, display_labels=data.target_names).plot(cmap="Blues", values_format="d")
plt.title("Decision Tree — held-out test set")
plt.show()
Teaching note: Because 0=malignant and 1=benign, sklearn’s default binary precision/recall (pos_label=1) would describe benign. We explicitly set pos_label=0 for malignant metrics. In the displayed matrix rows = actual and columns = predicted, both ordered [malignant, benign].
Quick check: With pos_label=0, which class does recall_score measure?

9. Optional: tune tree complexity with grid search

param_grid = {
    "criterion": ["gini", "entropy"],
    "max_depth": [2, 3, 4, 5, None],
    "min_samples_leaf": [1, 3, 5, 10]
}

search = GridSearchCV(
    DecisionTreeClassifier(random_state=42),
    param_grid=param_grid,
    cv=5,
    scoring="accuracy",
    n_jobs=-1
)
search.fit(X_train, y_train)
print("Best parameters:", search.best_params_)
print("Best cross-validation accuracy:", search.best_score_)

best_tree = search.best_estimator_
print("Tuned model test accuracy:", best_tree.score(X_test, y_test))
Teaching note: GridSearchCV searches complexity settings using only the training set, then evaluates the selected model on the held-out test set. Do not keep changing the grid based on the test score: that would leak test information.
