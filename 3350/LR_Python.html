X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.20, random_state=42, stratify=y ) print("Training samples:", X_train.shape[0]) print("Test samples:", X_test.shape[0])

What does stratify=y mean?

For a classification problem, y contains the class labels. Setting stratify=y tells train_test_split() to make the training and test sets preserve approximately the same class proportions as the original dataset.

For example, suppose the full dataset contains:

60% Class 1 and 40% Class 0.

With stratify=y, the split will try to keep approximately:

Training set → 60% Class 1, 40% Class 0
Test set → 60% Class 1, 40% Class 0
DatasetClass 0Class 1
Original data≈ 40%≈ 60%
Training data≈ 40%≈ 60%
Test data≈ 40%≈ 60%
Why is this useful?

Without stratification, a random split can accidentally create training and test sets with noticeably different class distributions, especially when the dataset is small or classes are imbalanced. Stratification makes the split more representative of the original class distribution.

Important: stratify=y does not balance the classes. It preserves their existing proportions.

4. Create the Pipeline

model = Pipeline([ ("scaler", StandardScaler()), ("logistic", LogisticRegression( max_iter=1000 )) ])
Raw X→StandardScaler→LogisticRegression
Why scale? The features have different numerical scales. Standardization generally helps numerical optimization and is especially important when regularization is used.

5. Train the Logistic Regression Model

model.fit(X_train, y_train) logistic_model = model.named_steps["logistic"] print("Number of iterations used:") print(logistic_model.n_iter_)
X_train, y_train→fit scaler→learn β coefficients→converge
During fit(), Logistic Regression numerically optimizes its objective. Conceptually, it learns coefficients that make the observed labels likely while accounting for the model's regularization settings.

What does n_iter_ mean?

Earlier we set max_iter=1000. This means the solver is allowed to use up to 1,000 iterations. It does not mean that it must run exactly 1,000 iterations.

After training, logistic_model.n_iter_ tells us how many iterations the solver actually used before stopping. For example, if it reports [15], the solver converged after 15 iterations even though max_iter was 1,000.

max_iter = maximum allowed iterations
n_iter_ = iterations actually used

7. Convert Probabilities into Class Predictions

y_pred = model.predict(X_test) print("First 10 predicted classes:") print(y_pred[:10]) print("\nFirst 10 actual classes:") print(y_test[:10])
predict() returns final class labels. For binary logistic regression, the default decision corresponds to choosing the class with the larger predicted probability (equivalent to a 0.5 threshold for class 1 in the ordinary binary case).

What does the colored plot show?

Each cell contains the number of samples for one actual/predicted combination. The color intensity provides a visual representation of the count, making the confusion matrix easier to read than the raw array alone.

The rows represent the actual classes, and the columns represent the predicted classes.

Important: In this dataset, 0 = malignant and 1 = benign. With scikit-learn's default binary metric convention, class 1 (benign) is treated as the positive class. Therefore, the upper-left cell is TN and the lower-right cell is TP.

9. Calculate Accuracy, Precision, Recall, F1, and Specificity

10. Print and Understand the Classification Report

print( classification_report( y_test, y_pred, target_names=data.target_names ) )
What does each class row mean?

The report calculates precision, recall, and F1-score separately for each class. For example, on the malignant row, malignant is treated as the class of interest; on the benign row, benign is treated as the class of interest.
ColumnMeaning
precisionOf the samples predicted as this class, how many were actually this class?
recallOf all actual samples of this class, how many did the model correctly identify?
f1-scoreThe harmonic mean of precision and recall.
supportThe number of actual samples belonging to this class in the test set.

What is support?

Suppose the report shows:

Malignant support = 42
Benign support = 72

Then the test set contains 42 actual malignant samples and 72 actual benign samples:

42 + 72 = 114 total test samples.

What is macro average?

Macro average gives every class equal importance, regardless of how many samples are in each class.

For two classes:

Macro Precision = (Precision_class0 + Precision_class1) / 2

So malignant and benign each contribute 50% to the macro average, even if one class contains many more samples.

Memory aid: Macro average → every class gets equal weight.

What is weighted average?

Weighted average accounts for the number of samples (support) in each class.

If there are 42 malignant and 72 benign samples:

Weighted Precision = (42 × Precision_malignant + 72 × Precision_benign) / 114

The benign class contributes more because it contains more samples.

Memory aid: Weighted average → larger classes get more weight.
Macro AverageWeighted Average
Class importanceEqualBased on support
Minority classSame importance as majority classContributes less
Useful forPerformance across classesOverall performance accounting for class sizes
Why compare macro and weighted averages?

If the model performs similarly on every class, macro and weighted averages will usually be similar. If they are very different, the model may be performing much better on a larger class than on a smaller class. This is especially useful to examine when classes are imbalanced.

Quick check: Suppose Class 0 has only 10 samples and Class 1 has 90 samples. Which average gives the two classes equal importance?

11. Inspect the Learned Coefficients

logistic_model = model.named_steps["logistic"] coefficients = logistic_model.coef_[0] intercept = logistic_model.intercept_[0] print("Intercept:") print(intercept) print("\nCoefficients:") for feature, coef in zip( data.feature_names, coefficients ): print(f"{feature:30s}: {coef:10.4f}")
Because the inputs were standardized inside the Pipeline, these coefficients correspond to standardized feature inputs. Positive coefficients increase the log-odds of class 1; negative coefficients decrease them, holding other features fixed.
