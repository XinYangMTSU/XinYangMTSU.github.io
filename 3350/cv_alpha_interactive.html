How Cross-Validation Picks the Best α

Try α → 5-fold CV → 5 validation errors → average → compare all α values → choose the smallest average error.

1. What are we choosing?

α controls regularization strength. Suppose our candidates are:

α = 0.001   |   0.01   |   0.1   |   1.0   |   10.0

We do not know which will generalize best, so cross-validation compares them.

2. Pick one α

Start with α = 0.1. We will evaluate this one candidate before moving to the others.

Current candidate: α = 0.1. Now split the training data into folds.

6. Compare the averages

Lower validation error is better. Which α wins?

We select α=1.0 because it has the smallest average validation error in this teaching example.

7. What happens after selection?

candidate α values → CV → average errors → best α

For estimators such as LassoCV and ElasticNetCV, the fitted estimator exposes the selected value as alpha_.

Important: the held-out test set should not be used to select α. Cross-validation chooses the hyperparameter using training data; the test set evaluates the final chosen workflow.
