1. Problem statement and initialization

We have five data points. Begin with each point as its own cluster. At each round, merge the two clusters with the smallest complete-linkage distance. We build the full dendrogram and then select a two-cluster solution.

4merges to one cluster

Initially: C1={P1}, C2={P2}, C3={P3}, C4={P4}, C5={P5}.

d(A,B) = max { d(a,b) : a ∈ A, b ∈ B } Complete linkage uses the largest cross-cluster pairwise Euclidean distance.

WCSS = Σ [ (x − μₓ)² + (y − μᵧ)² ] Sum of squared distances from each point to the centroid of its assigned cluster.

Cluster A calculation

P1: (2−3)² + (3−3.6667)² = 1.4444
P2: (2−3)² + (5−3.6667)² = 2.7778
P3: (5−3)² + (3−3.6667)² = 4.4444

WCSS(A) = 8.6667 ≈ 8.67

Cluster B calculation

P4: (6−7)² + (7−6.5)² = 1.25
P5: (8−7)² + (6−6.5)² = 1.25

WCSS(B) = 2.50

4.0Dendrogram cut height
Important distinctionAgglomerative complete linkage does not minimize WCSS. WCSS and centroids are supplementary ways to describe the chosen clusters, commonly used with K-means. They did not determine the merge order.
# For the two-cluster solution, compute means and WCSS afterward
Z = linkage(X, method="complete", metric="euclidean")
labels_2 = fcluster(Z, t=4.0, criterion="distance")
wcss = 0.0
for c in np.unique(labels_2):
    group = X[labels_2 == c]
    centroid = group.mean(axis=0)
    wcss += ((group - centroid)**2).sum()
    print("Cluster", c, "centroid:", np.round(centroid, 2))
print("WCSS:", round(float(wcss), 2))  # 11.17

STEP 10 / 12

10. Assign a new point (post-clustering heuristic)

Once the two clusters are formed, we can optionally assign a new point to the nearest cluster centroid. The example new point is Pnew(3,4).

This is not the agglomerative algorithm's built-in predictionUnlike K-means, AgglomerativeClustering does not provide a native predict() method. Assigning by nearest centroid is a convenient additional heuristic, not complete-linkage re-clustering. Adding the new point and rerunning hierarchical clustering could yield a different hierarchy.
Try a new point

Enter x and y. The page compares Euclidean distances to the two post-hoc cluster centroids: A=(3.00,3.67), B=(7.00,6.50).

For (3,4): distance to A = 0.33; distance to B = 4.72 → assign to Cluster A.
New point and the two cluster centroids
# Optional post-clustering nearest-centroid assignment
new_point = np.array([3.0, 4.0])
clusters = [X[labels_2 == labels_2[0]], X[labels_2 == labels_2[3]]]
centroids = np.array([group.mean(axis=0) for group in clusters])
distances = np.linalg.norm(centroids - new_point, axis=1)
print("Distances (A, B):", np.round(distances, 2))  # [0.33, 4.72]
print("Nearest cluster:", ["A", "B"][np.argmin(distances)])
# This is a separate heuristic, not AgglomerativeClustering.predict().

STEP 11 / 12

11. Compare all three linkages using Python

This complete runnable script computes single, complete, and average linkage on the same five points, plots all three dendrograms side by side, and plots their cluster assignments below. Try cut heights 3.2, 3.4, and 4.0 to compare how linkage changes the grouping.

"""CSCI 3350: Compare single, complete and average agglomerative linkage.
Save as compare_agglomerative_linkages.py and run with Python.
Dependencies: numpy scipy matplotlib.
This produces a six-panel figure: three dendrograms + three cluster plots.
"""

import numpy as np
import matplotlib.pyplot as plt
from scipy.spatial.distance import pdist, squareform
from scipy.cluster.hierarchy import linkage, dendrogram, fcluster

names = ["P1", "P2", "P3", "P4", "P5"]
X = np.array([[2, 3], [2, 5], [5, 3], [6, 7], [8, 6]], dtype=float)
methods = ["single", "complete", "average"]
cut_height = 3.40   # Compare results; try 2.50 or 4.00

print("Pairwise Euclidean distance matrix:")
print(np.round(squareform(pdist(X, metric="euclidean")), 2))

# Three dendrograms in row 1; cluster scatter plots in row 2.
fig, axes = plt.subplots(2, 3, figsize=(16, 9))
fig.suptitle("Agglomerative Clustering: Comparing Three Linkage Methods", fontsize=17)

for col, method in enumerate(methods):
    Z = linkage(X, method=method, metric="euclidean")
    labels = fcluster(Z, t=cut_height, criterion="distance")

    print(f"\n{method.upper()} linkage")
    print("Merge heights:", np.round(Z[:, 2], 4))
    for c in np.unique(labels):
        group = [names[i] for i in np.where(labels == c)[0]]
        print(f"  Cluster {c}: {group}")

    # Top: full hierarchical dendrogram and the SAME cut height.
    ax = axes[0, col]
    dendrogram(Z, labels=names, ax=ax, color_threshold=cut_height,
               above_threshold_color="gray")
    ax.axhline(cut_height, color="magenta", linestyle="--", linewidth=1.5)
    ax.set_title(f"{method.title()} linkage")
    ax.set_xlabel("Data points")
    ax.set_ylabel("Linkage distance")
    ax.set_ylim(bottom=0, top=7.1)
    ax.grid(axis="y", alpha=0.25)

    # Bottom: points colored according to groups from this dendrogram cut.
    ax = axes[1, col]
    for c in np.unique(labels):
        group = X[labels == c]
        ax.scatter(group[:, 0], group[:, 1], s=90,
                   label=f"Cluster {c}")
    for i, (x, y) in enumerate(X):
        ax.annotate(names[i], (x, y), xytext=(7, 7),
                    textcoords="offset points")
    ax.set_xlim(0, 10)
    ax.set_ylim(1, 9)
    ax.set_xlabel("x")
    ax.set_ylabel("y")
    ax.set_title(f"Cut = {cut_height:.2f}: {len(np.unique(labels))} clusters")
    ax.grid(alpha=0.25)
    ax.legend(loc="best", fontsize=9)

fig.tight_layout(rect=(0, 0, 1, 0.96))
fig.savefig("agglomerative_linkage_comparison.png", dpi=180, bbox_inches="tight")
plt.show()

# The three methods all give two groups at cut height 4.0:
# {P1,P2,P3} and {P4,P5}. Their merge heights are different.

12. Compare Single, Complete, and Average Linkage

Each method starts with the same Euclidean distances and merges the same closest pairs first. The definition of cluster-to-cluster distance changes the third and fourth merge heights. See the Single, Complete, and Average Linkage reference for the linkage concepts.

Single linkage

minimum Closest cross-cluster pair

Complete linkage

maximum Farthest cross-cluster pair

Average linkage

average Mean of all cross-cluster pairs

Complete: max(3.00, 3.61) = 3.61
