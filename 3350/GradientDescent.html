Gradient Descent

An intuitive, visual introduction to one of the fundamental optimization ideas in machine learning.

1) The Big Idea

Gradient descent is an iterative optimization algorithm used to find parameter values that make a loss function as small as possible.

Imagine this: You are standing on a mountain in thick fog. You cannot see the bottom. You feel the slope under your feet, take a small step downhill, check the slope again, and repeat until you reach the valley.
Choose parameters → Calculate loss → Find gradient → Move downhill ↻

2) What is a Gradient?

For one variable, the derivative tells us the slope. For many parameters, the gradient collects all partial derivatives into a vector.

∇L(β) = [ ∂L/∂β₁, ∂L/∂β₂, ..., ∂L/∂βₚ ]ᵀ

The gradient points toward the steepest increase. To minimize loss, we move in the opposite direction.

Gradient

Points toward the steepest uphill direction.

Negative Gradient

Points downhill—the direction used by gradient descent.

3) The Gradient Descent Update Rule

βnew = βold − η ∇L(βold)
SymbolMeaning
βModel parameter(s)
∇L(β)Gradient of the loss
ηLearning rate / step size

Example: let L(β)=(β−3)², so the derivative is 2(β−3). Starting at β=0 with η=.1:

βnew = 0 − 0.1 × 2(0 − 3) = 0.6

Then: 0 → 0.6 → 1.08 → 1.464 → 1.771 → ... → 3.

5) Why Does the Learning Rate Matter?

η too small

Tiny steps; convergence can be very slow.

η appropriate

Loss decreases efficiently toward the minimum.

η too large

The algorithm can overshoot and oscillate.

η much too large

The optimization can diverge.

6) Gradient Descent for Linear Regression

ŷ = β₀ + β₁x

Using mean squared error:

MSE = (1/n) Σ(yᵢ − ŷᵢ)²

Gradient descent updates both parameters using their partial derivatives:

β₀ ← β₀ − η ∂L/∂β₀    β₁ ← β₁ − η ∂L/∂β₁

7) OLS vs. Gradient Descent

OLS has a direct linear-algebra solution:

β̂ = (XᵀX)⁻¹Xᵀy

Therefore, OLS does not require gradient descent. But OLS defines an optimization objective, and gradient descent is another way to minimize that objective.

Closed-form / linear algebraGradient descent
Solves directlyApproaches the solution iteratively
No learning rateRequires a step size

8) Lasso and Coordinate Descent

The objective and the optimization algorithm are different concepts.

MethodTypical perspective
OLSClosed-form / linear algebra solution available
RidgeClosed-form / linear algebra solution available
LassoNo simple closed-form solution; iterative optimization
Elastic NetTypically iterative optimization

Lasso contains the L1 penalty λΣ|βⱼ|. Because |β| is not differentiable at zero, ordinary gradient descent is not the most natural solver. Coordinate descent is commonly used.

Gradient Descent

Uses gradient information to update all coefficients together.

Coordinate Descent

Optimizes one coefficient at a time while holding the others fixed.

Remember: Coordinate descent is not simply an advanced version of gradient descent. They are different iterative optimization strategies.

9) Python Example

def loss(beta):
    return (beta - 3) ** 2

def gradient(beta):
    return 2 * (beta - 3)

beta = 0.0
learning_rate = 0.1

for iteration in range(20):
    beta = beta - learning_rate * gradient(beta)
    print(iteration + 1, beta, loss(beta))
