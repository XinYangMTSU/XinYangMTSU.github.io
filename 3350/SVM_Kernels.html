4. How does the kernel trick help?

The SVM can use a kernel function to measure similarity as though observations were represented in a different feature space. It can thereby learn a nonlinear boundary in the original space.

K(xᵢ, xⱼ) = ⟨φ(xᵢ), φ(xⱼ)⟩

Original features

Inner and outer circles cannot be separated with a straight line in (x₁, x₂).

Transformed features

A feature like x₁² + x₂² captures distance from the center, making circular patterns easier to separate.
The kernel trick computes similarities without explicitly constructing every transformed feature. Not every kernel will suit every dataset.

5. Meet four SVM kernels

KernelFormula / intuition
LinearK(x,z) = x · z
PolynomialK(x,z) = (γ x · z + r)d
RBFK(x,z) = exp(−γ‖x−z‖²)
SigmoidK(x,z) = tanh(γ x · z + r)
Important: On symmetric concentric circles, a degree-2 polynomial can work well. The default degree-3 polynomial need not perform well. RBF is often a convenient general-purpose nonlinear kernel; sigmoid may not fit this geometry.

7. The RBF kernel

K(xᵢ, xⱼ) = exp(−γ ‖xᵢ − xⱼ‖²)

The RBF kernel assigns higher similarity to nearby observations. The gamma (γ) parameter controls how quickly similarity decreases with distance.

Small gamma

Each point influences a broader neighborhood. Boundaries tend to be smoother.

Large gamma

Influence becomes highly localized. Boundaries can become complex and overfit.

9. C versus gamma: What is different?

C — penalty

Controls the trade-off between margin regularization and violations of the classification constraints.

gamma — similarity scale

For RBF, controls how quickly similarity decreases with squared distance.
Both hyperparameters can change the fitted boundary. They interact, so tune them jointly using cross-validation on the training set.

10. Overfitting: Train accuracy vs test accuracy

Increasing model flexibility can improve training accuracy but does not guarantee generalization.

Underfitting

Boundary too simple for the pattern. Poor training and test performance.

Overfitting

Boundary follows training quirks or noise. Training performance may be excellent while test performance drops.

In a small test set, a few observations can change test accuracy substantially. Use repeated validation or cross-validation for reliable model selection.

12. Python: Generate data and compare kernels

Copy this scikit-learn version into Jupyter Notebook to recreate the central experiment with a validated library implementation.

from sklearn.datasets import make_circles from sklearn.model_selection import train_test_split from sklearn.preprocessing import StandardScaler from sklearn.pipeline import make_pipeline from sklearn.svm import SVC X, y = make_circles(n_samples=100, noise=0.05, factor=0.5, random_state=42) X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.2, stratify=y, random_state=42) models = { "Linear": SVC(kernel="linear", C=1), "Polynomial (degree 2)": SVC(kernel="poly", degree=2, C=1), "RBF": SVC(kernel="rbf", C=1, gamma="scale"), "Sigmoid": SVC(kernel="sigmoid", C=1) } for name, svm in models.items(): pipe = make_pipeline(StandardScaler(), svm) pipe.fit(X_train, y_train) print(f"{name:24s} " f"Train={pipe.score(X_train,y_train):.2%} " f"Test={pipe.score(X_test,y_test):.2%}")
The browser's educational SVM solver and scikit-learn's SVC use different numerical implementations. Their exact scores may differ slightly.

13. Python: Tune nonlinear SVM hyperparameters safely

from sklearn.model_selection import GridSearchCV pipeline = make_pipeline(StandardScaler(), SVC()) parameters = [ {"svc__kernel": ["linear"], "svc__C": [0.1, 1, 10]}, {"svc__kernel": ["poly"], "svc__degree": [2, 3, 4], "svc__C": [0.1, 1, 10]}, {"svc__kernel": ["rbf"], "svc__C": [0.1, 1, 10], "svc__gamma": [0.01, 0.1, 1, 10]} ] search = GridSearchCV(pipeline, parameters, cv=5, scoring="accuracy") search.fit(X_train, y_train) print("Best parameters:", search.best_params_) print("Best cross-validation score:", search.best_score_) print("Final test accuracy:", search.score(X_test, y_test))
The scaler is inside the pipeline, and cross-validation only uses training data. Evaluate on the untouched test set once after selecting hyperparameters.
