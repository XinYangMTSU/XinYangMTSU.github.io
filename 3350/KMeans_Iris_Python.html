3. Scale the four features

Use StandardScaler so variables contribute in standardized units to Euclidean distance.

# Standardize all four features before clustering
scaler = StandardScaler()

# Check the transformed feature means and standard deviations
print("Scaled means:", X_scaled.mean(axis=0).round(3))

Why this mattersScaling is important because K-means minimizes distances. All four scaled features will be used during clustering. The scatter plot later displays two original features only.

STEP 4 / 9

4. Use the elbow method to explore k

Fit models for k=1 through k=10. Watch how inertia (within-cluster sum of squares) decreases as k increases.

# Test k = 1 to 10 using within-cluster sum of squares (WCSS)
ks = range(1, 11)
inertias = []
for k in ks:
    km = KMeans(n_clusters=k, init="k-means++",
                n_init=10, random_state=42)
    km.fit(X_scaled)
    inertias.append(km.inertia_)

plt.figure()
plt.plot(ks, inertias, marker="o")
plt.title("Elbow Method (Iris, scaled)")
plt.xlabel("k")
plt.ylabel("Inertia (WCSS)")
plt.xticks(list(ks))
plt.grid()
plt.tight_layout()
plt.show()

# Choose k=3 as in the provided example
k = 3
Why this mattersInertia (WCSS) adds squared distances from each flower to its assigned centroid, in standardized four-dimensional space. More clusters typically reduce inertia even when the extra clusters are not useful.
Elbow method · standardized Iris dataHover on any point for inertia

STEP 5 / 9

5. Fit the final model with k = 3

Run K-means++ with 10 initializations and random_state=10, matching the final model in your example.

# Fit the final K-means model on ALL FOUR scaled features
kmeans = KMeans(n_clusters=k, init="k-means++",
                n_init=10, random_state=10)
labels = kmeans.fit_predict(X_scaled)

print("Cluster sizes:", np.bincount(labels))
print("Final inertia (WCSS):", kmeans.inertia_)
print("Centroids in scaled space:\n", kmeans.cluster_centers_)
Why this mattersCluster numbers are algorithm-assigned identifiers, not the names setosa, versicolor, and virginica. Centroids from cluster_centers_ are given in scaled units.

6. Visualize the clusters in two dimensions

The scatter plot shows original flower measurements, colored by the cluster assignments learned using all four scaled features.

# Visualize two original, unscaled features
# (Cluster labels were learned from all four scaled features.)
i, j = 0, 1             # Sepal length vs. sepal width
plt.figure()
for c in range(k):
    mask = (labels == c)
    plt.scatter(X[mask, i], X[mask, j],

plt.xlabel(feature_names[i])
plt.ylabel(feature_names[j])
plt.title("K-Means clusters on two original features")
plt.grid()
plt.legend()
plt.tight_layout()
plt.show()
Why this mattersThe mask = (labels == c) expression selects rows belonging to a cluster. Two plotted axes are a projection; the model itself is fitted using four features.

STEP 7 / 9

7. Predict clusters for new flowers

Apply the already fitted scaler to new samples, then use the trained K-means model to assign their nearest centroids.

# New rows follow this order:
# sepal length, sepal width, petal length, petal width
new_samples = np.array([
    [5.0, 3.5, 1.3, 0.3],  # Setosa-like
    [6.0, 2.7, 5.1, 1.6],  # Versicolor/Virginica-like
])
new_scaled = scaler.transform(new_samples)  # Do not refit!
pred = kmeans.predict(new_scaled)
print("Predicted clusters for new samples:", pred)
Why this mattersUse scaler.transform(new_samples)—not fit_transform—so the new flowers are standardized with the original training means and standard deviations.

9. Experiment: change the number of clusters

This interactive extension uses precomputed scikit-learn K-means outputs so students can explore k without installing Python.

# Experiment: change k and compare the result
for trial_k in [2, 3, 4, 5]:
    trial = KMeans(n_clusters=trial_k, init="k-means++",
                   n_init=10, random_state=42)
    trial_labels = trial.fit_predict(X_scaled)
    print(f"k={trial_k}: inertia={trial.inertia_:.2f}, "
          f"cluster sizes={np.bincount(trial_labels).tolist()}")

# Compare cluster geometry, inertia, and sizes—but remember that
