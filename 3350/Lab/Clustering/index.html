Part 2 — Work through the mathematics

1. High-dimensional similarities

For each high-dimensional point xi, a Gaussian kernel produces conditional probabilities:

pj|i = exp(−‖xi − xj‖² / 2σi²) / Σk≠i exp(−‖xi − xk‖² / 2σi²)

Perplexity controls the effective scale of each point's neighborhood by adjusting σi. Symmetrization yields pij = (pj|i + pi|j)/(2n).

2. Low-dimensional similarities

A heavy-tailed Student-t kernel with one degree of freedom defines qij ∝ (1 + ‖yi − yj‖²)−1, normalized across all distinct pairs. The heavy tails help alleviate crowding.

3. Minimize mismatch

The t-SNE objective is KL(P‖Q) = Σi≠j pij log(pij/qij). The asymmetry matters: missing a genuine high-dimensional neighbor in the 2D embedding is strongly penalized.
