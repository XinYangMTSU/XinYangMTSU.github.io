From Linear Regression to Elastic Net

Learn the family as one story: fit a line → add curves → control coefficients → shrink → select → combine.

Step 1 of 11

Start with Linear Regression

We have data points and want a model that predicts y from x.

ŷ = β₀ + β₁x

Sum of squared errors (SSE):

Goal: choose β₀ and β₁ so predictions are close to observed y values. The vertical gaps are residuals.
Step 2 of 11

Why square the residuals?

SSE = Σ(yᵢ − ŷᵢ)²

Residuals can be positive or negative. If we simply add them, they can cancel. Squaring makes every contribution nonnegative and penalizes large errors more strongly.

Ordinary Least Squares (OLS) finds coefficients that minimize the sum of squared residuals.
Step 3 of 11

What if a straight line is not enough?

Some relationships are curved. Polynomial regression adds transformed versions of x as features.

Degree 1: ŷ = β₀ + β₁x

Degree 2: ŷ = β₀ + β₁x + β₂x²

Degree 3: ŷ = β₀ + β₁x + β₂x² + β₃x³

Important: Polynomial regression is still linear regression with respect to the coefficients β. We changed the features by adding x², x³, etc.
Step 4 of 11

More flexibility can become overfitting

A high-degree polynomial can bend enough to follow noise in the training data.

Underfitting

Model is too simple to capture the important pattern.

Overfitting

Model follows training data too closely and may perform poorly on new data.

Which result is the real goal?

Step 5 of 11

Regularization: add a penalty

Instead of minimizing prediction error alone, we can also discourage very large coefficients.

Prediction Error+Coefficient Penalty=New Objective
The tuning parameter α (alpha) controls penalty strength. α = 0 means no regularization. Larger α means stronger pressure to shrink coefficients.

Why might smaller coefficients help?

Step 6 of 11

Ridge Regression: shrink coefficients

Ridge objective = SSE + α Σ βⱼ²

Move α and watch illustrative coefficients shrink.

Ridge uses an L2 penalty. It usually shrinks coefficients toward zero but does not force them exactly to zero. It is useful when many features may contribute.
Step 7 of 11

Lasso: shrink AND select

Lasso objective = SSE + α Σ |βⱼ|

Move α. Notice that some illustrative coefficients become exactly zero.

Lasso uses an L1 penalty. Because coefficients can become exactly zero, Lasso can perform feature selection.
Step 8 of 11

Ridge vs. Lasso

RidgeLasso
PenaltyL2: Σβ²L1: Σ|β|
Shrink coefficients?YesYes
Exact zeros?Usually noYes, possible
Intuition“How much should each feature be shrunk?”“Which features are really needed?”

Suppose you want a sparse model where some features disappear completely. Which is more directly designed for that?

Step 9 of 11

Elastic Net: combine Ridge + Lasso

Elastic Net = SSE + α[(1 − r)/2 · Σβⱼ² + r · Σ|βⱼ|]

r = l1_ratio controls the mixture.

r = 0

Ridge-like: L2 side dominates.

r = 1

Lasso: L1 side dominates.
Elastic Net is useful when you want both coefficient shrinkage and sparsity, especially when predictors are correlated.

Step 11 of 11

Mastery Check: identify the model

Scenario: You have many correlated predictors. You want shrinkage, but you also want some feature selection. Which model combines L1 and L2 penalties?

The whole story:
Linear Regression → fit a linear relationship.
Polynomial Regression → give the linear model curved features.
Ridge → shrink coefficients with L2.
Lasso → shrink and possibly set coefficients to zero with L1.
Elastic Net → combine L1 and L2.
