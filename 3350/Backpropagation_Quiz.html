Lecture reference: the network

4 inputs → 3 hidden neurons → 1 output
Input x = [1, 2, 0.5, −0.5], true label y = 1, learning rate α = 0.1.
W¹ (rows: inputs, columns: hidden) [ 0.5 0.2 -0.1 ] [ 0.3 0.4 0.2 ] [-0.2 0.1 0.5 ] [ 0.1 0.3 -0.2 ] b¹ = [0.1, 0.2, 0.15] W² = [0.6, 0.2, 0.5] b² = 0.05
Notation: x is treated as a row vector for the table shown above; hidden neuron j computes z¹ⱼ = Σᵢ xᵢW¹ᵢⱼ + b¹ⱼ. The full output is z² = Σⱼ hⱼW²ⱼ + b².
