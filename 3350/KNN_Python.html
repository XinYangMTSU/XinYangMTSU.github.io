K-Nearest Neighbors (KNN) in Python: Grid Search Workflow

8-step interactive walkthrough. Instead of choosing k=5 in advance, GridSearchCV selects the best KNN model using the training data.

1. Import Required Libraries

import numpy as np import matplotlib.pyplot as plt from sklearn.datasets import load_breast_cancer from sklearn.model_selection import train_test_split, GridSearchCV from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.neighbors import KNeighborsClassifier from sklearn.metrics import ( accuracy_score, precision_score, recall_score, f1_score, confusion_matrix, ConfusionMatrixDisplay, classification_report )
Goal: load a classification dataset, split the data, scale the features, use grid search to select the best KNN hyperparameters, make predictions, and evaluate the final model.

2. Load the Breast Cancer Dataset

data = load_breast_cancer() X = data.data y = data.target print("X shape:", X.shape) print("y shape:", y.shape) print(data.feature_names) print(data.target_names)
X contains 30 numeric features. y contains the class labels: 0 = malignant and 1 = benign.

3. Split into Training and Test Sets

X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.20, random_state=42, stratify=y ) print(X_train.shape, X_test.shape)
TRAIN 80%
TEST 20%
stratify=y preserves approximately the original class proportions in both the training and test sets.

What does stratify=y do?

4. Create the Pipeline

z = (x − μ) / σ
knn_pipe = Pipeline([ ("scaler", StandardScaler()), ("knn", KNeighborsClassifier()) ])
Why scale? KNN is distance-based. Features with large numeric scales can dominate the distance calculation. Putting StandardScaler() inside the pipeline also ensures that scaling is learned separately within each cross-validation training fold.

5. Use Grid Search to Find the Best KNN Model

param_grid = { "knn__n_neighbors": [3, 5, 7, 9, 11, 15], "knn__weights": ["uniform", "distance"], "knn__metric": ["euclidean", "manhattan"] } grid = GridSearchCV( knn_pipe, param_grid, cv=5, scoring="accuracy", n_jobs=-1 ) grid.fit(X_train, y_train) print("Best parameters:", grid.best_params_) print("Best CV accuracy:", grid.best_score_) best_model = grid.best_estimator_
GridSearchCV tries every specified combination using 5-fold cross-validation on the training set only. The test set remains untouched until final evaluation.

6. Make Predictions with the Best Model

y_pred = best_model.predict(X_test) print("First 10 predictions:", y_pred[:10]) print("First 10 actual labels:", y_test[:10])
The model selected by GridSearchCV is now applied to X_test. These predictions are used for the final evaluation.

7. Evaluate Accuracy, Precision, Recall, Specificity, and F1

accuracy = accuracy_score(y_test, y_pred) precision = precision_score(y_test, y_pred) recall = recall_score(y_test, y_pred) f1 = f1_score(y_test, y_pred) tn, fp, fn, tp = confusion_matrix(y_test, y_pred).ravel() specificity = tn / (tn + fp) print(f"Accuracy: {accuracy:.4f}") print(f"Precision: {precision:.4f}") print(f"Recall: {recall:.4f}") print(f"Specificity: {specificity:.4f}") print(f"F1 Score: {f1:.4f}") print("\nClassification Report:") print(classification_report( y_test, y_pred, target_names=data.target_names ))
Accuracy

F1 Score

Harmonic mean of precision and recall

Important: because the dataset uses 1 = benign as the positive class, the default precision and recall above describe the benign class. The classification report displays metrics for both malignant and benign classes.

8. Confusion Matrix and Complete Workflow
