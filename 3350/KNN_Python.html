K-Nearest Neighbors (KNN) in Python: Step by Step

12-step interactive walkthrough. Every code block can be copied into a Jupyter Notebook in order.

1. Import All Required Libraries

import numpy as np import matplotlib.pyplot as plt from sklearn.datasets import load_breast_cancer from sklearn.model_selection import train_test_split, GridSearchCV from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.neighbors import KNeighborsClassifier from sklearn.metrics import (accuracy_score, precision_score, recall_score, f1_score, confusion_matrix, ConfusionMatrixDisplay, classification_report)
Why? We need a dataset, train/test splitting, scaling, KNN, hyperparameter tuning, and evaluation metrics.

2. Load the Breast Cancer Dataset

data = load_breast_cancer() X = data.data y = data.target print("X shape:", X.shape) print("y shape:", y.shape) print(data.feature_names) print(data.target_names)
X contains 30 numeric features. y contains labels: 0 = malignant, 1 = benign.

3. Split into Training and Test Sets

X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.20, random_state=42, stratify=y ) print(X_train.shape, X_test.shape)
TRAIN 80%
TEST 20%
stratify=y preserves approximately the original class proportions.

Quick check: what does stratify do?

4. Why Scaling Is Essential

z = (x − μ) / σ
Without scaling

Large-unit features can dominate distance.

With scaling

Features become comparable before distances are computed.

KNN is distance-based. Scaling can directly change which samples are nearest neighbors.

5. Create the KNN Pipeline

model = Pipeline([ ("scaler", StandardScaler()), ("knn", KNeighborsClassifier( n_neighbors=5, metric="minkowski", p=2, weights="uniform" )) ])
Raw X→StandardScaler→KNN
SettingMeaning
n_neighbors=5Use 5 neighbors
p=2Euclidean distance
weights="uniform"Equal votes

6. Fit the KNN Model

model.fit(X_train, y_train) knn_model = model.named_steps["knn"] print("k:", knn_model.n_neighbors) print("Stored training samples:", knn_model.n_samples_fit_)
KNN is lazy / instance-based. It does not learn β coefficients or a global equation. It stores training instances for later comparison.

7. Inspect the Nearest Neighbors

sample_scaled = model.named_steps["scaler"].transform(X_test[:1]) distances, indices = knn_model.kneighbors(sample_scaled, n_neighbors=5) print("Distances:", distances) print("Neighbor indices:", indices) print("Neighbor labels:", y_train[indices[0]])
kneighbors() shows exactly which stored training samples are closest to a new sample.

If labels are [1,1,0,1,0], what is the uniform-vote prediction?

8. Predict Classes and Probabilities

y_pred = model.predict(X_test) y_prob = model.predict_proba(X_test) print(y_pred[:10]) print(y_prob[:5]) print(y_prob[:5, 1])
With uniform weights, probabilities reflect class proportions among the selected neighbors. With k=5, 3 Class-1 neighbors and 2 Class-0 neighbors give P(1)=0.60 and P(0)=0.40.

9. Confusion Matrix

cm = confusion_matrix(y_test, y_pred) print(cm) tn, fp, fn, tp = cm.ravel() print("TN:",tn,"FP:",fp,"FN:",fn,"TP:",tp) disp = ConfusionMatrixDisplay( confusion_matrix=cm, display_labels=data.target_names ) disp.plot(cmap="Blues", values_format="d") plt.title("KNN Confusion Matrix") plt.show()

10. Accuracy, Precision, Recall, Specificity, F1

accuracy = accuracy_score(y_test, y_pred) precision = precision_score(y_test, y_pred) recall = recall_score(y_test, y_pred) f1 = f1_score(y_test, y_pred) tn, fp, fn, tp = confusion_matrix(y_test, y_pred).ravel() specificity = tn / (tn + fp) print(f"Accuracy: {accuracy:.4f}") print(f"Precision: {precision:.4f}") print(f"Recall: {recall:.4f}") print(f"Specificity: {specificity:.4f}") print(f"F1 Score: {f1:.4f}")

11. Tune k, Distance, and Weights

param_grid = { "knn__n_neighbors": [3, 5, 7, 9, 11, 15], "knn__weights": ["uniform", "distance"], "knn__p": [1, 2] } grid = GridSearchCV( model, param_grid, cv=5, scoring="accuracy", n_jobs=-1 ) grid.fit(X_train, y_train) print("Best parameters:", grid.best_params_) print("Best CV accuracy:", grid.best_score_) best_model = grid.best_estimator_
p=1 → Manhattan; p=2 → Euclidean.

Keeping the scaler inside the Pipeline means scaling is fit separately inside each CV training fold, helping avoid preprocessing leakage.

12. Evaluate the Tuned Model + Curse of Dimensionality

y_pred_best = best_model.predict(X_test) print( classification_report( y_test, y_pred_best, target_names=data.target_names ) )
Curse of dimensionality: as the number of features grows, observations become sparse and distances can become less informative. Irrelevant features can distort neighborhoods.
Feature selection

Remove irrelevant/redundant variables.

Dimensionality reduction

Consider PCA or another appropriate representation.

Scaling

Prevents units from unfairly dominating distance, although it does not reduce dimensionality.

Validation

Compare k, metric, weights, and preprocessing using cross-validation.

High-D X→Scale→Select / Reduce Features→KNN
