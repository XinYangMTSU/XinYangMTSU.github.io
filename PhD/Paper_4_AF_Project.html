Prediction, Replication, and Multimodal Extension of Autism Language Development

This webpage is a practical research-and-publication roadmap for paper 4 in the longitudinal autism neuroimaging dissertation sequence.

Can early localized arcuate fasciculus developmental features improve prediction and generalization of later language outcomes, and do the discovered relationships replicate across cohorts or modalities?

Scientific progression

Known: Early imaging can contain information about later outcomes.
Known: Prediction alone does not establish biological meaning.
Gap: Generalizability of localized AF developmental biomarkers remains uncertain.
Contribution: Test incremental predictive value, replication, and optional structure–function extension.

4. Step-by-step implementation

Use this as the student's operational checklist.

Define prediction target

Choose a clinically meaningful later expressive or receptive language outcome.

Baseline model

Use age, baseline language, sex, IQ, and clinical measures.

Imaging-only model

Use early localized AF features with dimensionality control.

Combined model

Add AF features to the baseline model and test incremental value.

Leakage-safe preprocessing

Fit scaling, feature selection, harmonization, and tuning only within training folds.

Nested validation

Use nested CV or leave-one-site-out validation; group all visits from a child together.

Model comparison

Start with Elastic Net; compare SVR, RF, or XGBoost only if justified.

Calibration and error

Report MAE/RMSE, calibration, confidence intervals, and subgroup errors.

Incremental utility

Test whether imaging materially improves prediction beyond baseline clinical variables.

External replication

Freeze the pipeline and test it on an independent cohort.

Optional fMRI extension

If matched fMRI exists, test whether language-network functional measures add value.

Interpretability

Use stable coefficients or permutation-based importance; avoid causal claims.

Figures

Show calibration, predicted-vs-observed outcomes, site generalization, and incremental value.

Manuscript

Conclude with generalizability and biomarker potential, not diagnostic classification.
