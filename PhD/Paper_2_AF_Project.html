Within-child brain–language coupling

Localized Arcuate Fasciculus Development and Expressive–Receptive Language Trajectories

This webpage is a practical research-and-publication roadmap for paper 2 in the longitudinal autism neuroimaging dissertation sequence.

When localized arcuate fasciculus microstructure changes within an autistic child, are those changes associated differently with expressive and receptive language development?

Scientific progression

Known: AF microstructure is associated with language ability.
Known: Longitudinal AF–language links have been observed in infancy.
Gap: Localized within-child AF change and domain-specific language change remain poorly resolved.
Contribution: Separate expressive and receptive trajectories and link them to tract-local within-child change.

1. Paper scope

Keep this paper focused on one coherent biomedical/computational contribution.

Core contribution: Separate expressive and receptive trajectories and link them to tract-local within-child change.

2. Specific aims

These aims should map directly to the Results section and major figures.

Aim 1

Estimate expressive and receptive language trajectories within autistic children.

Aim 2

Test whether localized AF changes track within-child language changes.

Aim 3

Determine whether AF–language coupling differs by tract location, hemisphere, and language domain.

4. Step-by-step implementation

Use this as the student's operational checklist.

Phenotype audit

Identify consistent expressive/receptive instruments across visits.

Score harmonization

Define primary language outcomes and standardize only when scientifically justified.

Reuse Paper 1 pipeline

Freeze tract definitions, QC, and node profiles before examining language outcomes.

Language trajectory models

Fit mixed-effects models for expressive and receptive scores separately.

Within-between decomposition

Separate a child’s average AF level from visit-specific deviations around that child’s mean.

Primary brain–language model

Test whether within-child AF change predicts within-child language change.

Domain comparison

Formally test whether AF effects differ for expressive versus receptive language.

Spatial localization

Map which tract nodes show the strongest brain–language relationships.

Hemisphere analysis

Test left/right differences as a secondary, prespecified analysis.

Covariate strategy

Handle age, sex, motion, site, IQ, baseline language, and missingness carefully.

Nonlinear sensitivity

Evaluate whether age moderates AF–language coupling.

Replication

Validate the strongest tract-region effects in another cohort/site if feasible.

Figures

Create paired trajectory plots and tract maps linking brain and language change.

Manuscript

Center the paper on developmental neurobiology, not prediction accuracy.
